# 『かえりみち』裏設計書　その三：エンディング

> 本編ED六種：それぞれ 3500字前後（±15%）、場面を五〜七つ。
> 追加ED二種：それぞれ 6000字前後、場面八〜九つまで。
> ノーマル・バッド・死亡にも、トゥルーやメリバと同じ長さと密度を与える。
> 軸：**誰が、誰の過去を語るか**（design.md の 3）。
> 各EDの頭で `@vis v3 …` を切り替える（design.md の 8）。

---

## 本編ED共通の前提

- ed01・ed02・ed04・ed06 は、第十五章の刑場の上、継が巻物を開いた直後から始まる。
- ed03・ed05 は、第十四章の門前の宿駅、仁科が外へ出ている「一刻」の中から始まる。
- どのEDでも、継の敬語と生意気は最後まで残す。息が切れても残す。
- 口づけの温度：トゥルーは可愛らしい、ためらいのある一回か二回。メリバと追加EDは何度も啄ばむ（制作ルールの描写の方針を参照）。口づけのたびに角がどう邪魔をして、どう二人を囲うかを書く（角の渦が継の顔の横に来る、角の先が眼鏡のつるに引っかかる、など）。
- 口づけの最中の息遣いは台詞で。同じ型を繰り返さない。

## ed01　トゥルー「みちしるべ」（`@vis v3 straight`）

条件：王都へ入る → 本当のことを読ませる → `p1 >= 20`

1. **読み上げ**：継は巻物を読まない。自分の口で読む。八年前の自分の証言が嘘だったこと。半分本当で半分嘘だったこと。自分が作った言葉を、一つずつ取り消す（「違います」の癖が、ここで初めて自分自身に向く）。続けて、三人の殉教の仕組み、茅野の白い灰、布告の日付、封書の「単独にて」。群衆がざわめく。
2. **典膳の合図**：典膳が桟敷から、穏やかに「幕を」と言う。天城が震えながら模造の剣を抜いて斬りかかる。仁科が斧を下ろす。**振らない**。「俺の仕事は、罪人の首だ」。
3. **対等の封**：天城の剣が先輩に届く寸前、先輩が継の胸の痣に手を当てて、縛魂の誓句を唱え返す（元聖騎士が、今度は自分の意志で）。封が双方向になり、魔王座は行き場を失う。先輩の角の根元から黒い渦が噴き上がり、宙で裂けて、昼の光の中に散る。角環が割れて石畳に落ちる。
4. **残ったもの**：先輩の角は残る（座は抜けたが、体に生えたものは戻らない）。継の胸の痣も、薄くなって傷痕として残る。先輩はもう魔王ではない。けれど石動で殺した人たちは戻らない。群衆の中で、陽太が石を下ろす。全員ではない。石を投げ続ける者もいる。先輩はそれを受ける。
5. **それから**：典膳は王の前で査問にかけられる（勝ちきらない。正義がどこへ行くかは分からない）。継は僧籍を剥奪される。二人は王都を出る。封はもうない。街道の途中で、継が試しに三十歩より先まで歩いてみる。何も起きない。継は立ち止まって、自分の足で戻ってくる。
6. **夜牧城の礼拝堂**：二人で戻り、三人をちゃんと葬る。祈りは長い。先輩も祈る。帰り際、崩れた礼拝堂で、口づけ。継からか先輩からかは作者に任せる。ためらいのある、可愛らしい一回（多くても二回）。角が邪魔で継が首を傾けすぎて眼鏡がずれる。息の仕方が分からない継の途切れた台詞。
7. **締め**：二人は石動へ向かう（慰霊の碑のそばで、残りの人生の使い道を決める、と先輩が言う）。道はもう輪ではない。

- 着地の温度：静かな幸せ。何も治っていないし、全部は戻らない。正常な判断が効いている。
- 【書き方】群衆の歓声で終わらせない。二人の足音で終わらせる。

## ed02　メリバ主人公主体「嘘の魔王」（`@vis v3 crown`）

条件：王都へ入る → 書かれた通りに読ませる → `p2 >= p3`

1. **読み上げ**：継は巻物の通りに読む。自分が八年前に作った言葉を、そのまま。「神々は嘘つきだ」。「私は闇のほうが好きだ」。声が震えない。群衆が沸く。
2. **先輩の選択**：先輩は、継の言葉を聞きながら笑う。その言葉のとおりの魔王に、自分からなることを決める。魔王座を拒まず、全部を抱き込む。角が育ち、太く長く巻き、角環が内側から割れる。仁科の斧が届く前に、刑場が影に沈む。
3. **縛り返し**：先輩は継の胸に手を当て、封を逆向きに結ぶ。座を継に流すためではなく、継を自分に繋ぐために。「君が語った魔王は、ひとりぼっちじゃなかったろう？」（【書き方】文言は作る。方向だけ）
4. **夜牧城**：二人は夜牧城に帰る。先輩は、継が証言で語った魔王の台詞を、一言一句、本当に言う。継が作った悪を、全部、本当のことにしていく。継はもう嘘つきではない。継は、自分が語ったとおりの魔王が目の前にいることが、嬉しくてたまらない。
5. **国**：王国には本物の魔王が生まれた。死なないので、もう八年の輪は回らない。典礼院の劇は終わった。代わりに、本物の恐怖が始まった。
6. **口づけ**：玉座の間で。何度も啄ばむ。角の渦が継の頭を囲うように。継が何か言いかけるたびに塞がれて、言い訳が文にならない。息が上がったまま敬語で強がる継。先輩は継の言葉を一つずつ口移しで「本当のこと」にしていく、という温度。
7. **締め**：継が新しい布告を書く。今度は、全部本当のことを。署名は継の名前。

- 軸：先輩が、継の嘘を本当にする。
- 狂気：両方。先輩は、自分の人生を継の嘘に明け渡して幸せ。継は、自分の嘘が真実になって救われている。どう考えても両方やばい。
- 【書き方】狂気は穏やかな口調のまま。先輩は継を見下さない。継は怯えていない。互いに差し出し合っている。

## ed03　メリバ後輩主体「語り部」（`@vis v3 off`）

条件：王都へ入らない → `p3 > p2 && p3 > p1`

1. **門前の宿駅**：仁科が外へ出ている一刻。継が先輩の手を取り、門に背を向ける。「行きましょう、先輩。街道じゃないほうへ」。
2. **街道を外れる**：二人は宿駅のない荒れ野へ入る。宿駅がなければ、記録帳もない。先輩の記憶は、もうどこにも置いていない。**これ以上、戻らない**。継はそれを分かっていて、選んでいる。
3. **夜ごとの話**：野宿の夜ごと、継が先輩に八年前の話をする。先輩の覚えていない旅の話。本当の話と、継が足した話が混ざっている。継が偽証しなかった旅。継がずっと先輩の隣にいた旅。先輩が継を選んだ旅。先輩は、どこからが継の足した話か分かっている。分かっていて、続きをせがむ。
   - 【書き方】書き換えは口で語るだけ。記録帳や紙に書いて偽ることはしない。
4. **痣と角**：封は残っている。先輩が死なないかぎり座は流れないが、導管から少しずつ滲んでくる。継の額に、小さな角の芽が出始めている。先輩の角は少しずつ細くなる。何年かかけて、二人は入れ替わっていくのかもしれない。継は「そのときは、今度は僕が先輩の話をしてあげます。あなたが魔王だったころの話を」と言う。
5. **口づけ**：話の途中で何度も。語りを途切れさせて啄ばみ、また続きを語る。先輩は話の続きをせがむ代わりに口づけをせがむ。「先輩、今どこまで話しましたっけ」。
6. **締め**：荒れ野の焚き火。遠くに王都の祭りの灯が見える。凱旋祭は、魔王のいないまま開かれている。継が「昔々」と始める。

- 軸：継が、先輩の過去の唯一の語り手になる。
- 狂気：両方。継は先輩の記憶を自分の手の中だけに置いておきたい。先輩は、自分の本当の過去より継の話す過去のほうが好きだと言う。
- 【書き方】継の独占欲は穏やかで、丁寧で、湿度が高い。先輩を閉じ込めるのではなく、世界のほうを閉め出す。

## ed04　バッド「千秋楽」（`@vis v3 loop`）

条件：王都へ入る → 書かれた通りに読ませる → `p2 < p3`

1. **読み上げ**：継は巻物の通りに読む。先輩は抗わない。先輩は、継が選ぶことを継に任せた。群衆が沸く。典膳が満足そうに頷く。
2. **斧**：仁科が振る。【書き方】首が落ちる瞬間は書かない。暗転。音。群衆の声が一段遅れて届く。
3. **継承**：魔王座が継に流れ込む。継の額から角が生える。継の中から、四十日の旅が焼けて消えていく。【書き方】消えていくものを、継の一人称の断片で短く並べる（鈴生の眼鏡屋の棚、鶴見の杏、千代川の舟酔い、先輩の笑い声）。最後の一つが消えるところで切る。
4. **大聖堂の地下**：新しい魔王は転移門の前に立たされる。典膳が、新しい角環を嵌める。聖銀ではない。黒い。**先輩の角を削って作った輪**。【書き方】典膳は「形見は、本人に」と嬉しそうに言う。継はそれが何か分からない。置かれた物と、典膳の口元と、継の指先の感覚だけで見せる。
5. **八年後の夜牧城**：玉座の新しい魔王。角環に触れていると、なぜか叱られている気がする、とひとりごとを言う。あたたかい。誰かの手が冷たかった気がする。城の外に、新しい勇者一行が来た。その中に、若い修道士が一人いる。
6. **締め**：典膳の声。「次の幕を」。

- 軸：典礼院が二人の過去を語り続ける。二人はもう自分の話を持っていない。
- 救いなし。でも二人は離れていない。一番最悪な形で、ずっと一緒。
- 【書き方】劇薬として書く。救いの気配を差し込まない。最後の一行まで典膳の劇の中。

## ed05　ノーマル「つづきの頁」（`@vis v3 halt`）

条件：王都へ入らない → ed03 の条件を満たさない

1. **門前の宿駅**：一刻。先輩が、自分から決める。凱旋祭には出ない。王都には入らない。継も入れない。
2. **封を切る**：先輩は、縛魂の封を自分の側から断ち切る。導管を無理に切るので、先輩の中の旅の記憶がもう一度焼ける。宿駅で拾い直した記憶が、また全部なくなる。継は止める。止めきれない。
3. **別れ**：封が切れた継の胸の痣は薄れていく。先輩は、自分で角環を外す（締め方を知っていた人は、外し方も知っている）。「夜牧城に帰る。座は私が持ったまま死なずにいる。そうすれば、もう誰にも流れない」。継の顔を見て、少し首を傾げる。旅のあいだの継を、もう覚えていない。修道院の小さな子のことは覚えている。「大きくなったね」。
   - 【書き方】「初めまして」の再会の形にはしない。先輩は継を知っている。ただ、この四十日の継を知らない。
4. **継**：先輩が北へ歩いて行くのを、継は見送る。三十歩より先へ行っても、何も起きない。何も起きないことが、一番こたえる。
5. **それから**：継は灰原の聖堂守になる。夜牧城には行かない（先輩が行くなと言った。行けば封が結び直ってしまうかもしれない）。継は毎日、記録帳に書く。先輩が八年前に書いた記録の、すぐ次の頁から。
6. **締め**：継の記録。報告書の文体。「冬の月九日　雪。灰原より北、変わりなし。魔物の出没なし。先輩は元気でいる、と思う。」数日ぶんの記録で終える。最後の一件だけ、文体が一行崩れる。

- 軸：継が一人で書き続ける。語る相手のいない記録。
- ずっと覚えているのは継。先輩は忘れた。
- 【書き方】寂しさは説明しない。記録の淡々さに任せる。

## ed06　死亡・解放「晴天」（`@vis v3 half`）

条件：王都へ入る → 本当のことを読ませる → `p1 < 20`

1. **読み上げ**：継は本当のことを読む（ed01 と同じ中身だが、書き方は変える。ed01 は取り消すこと、ed06 は叫ぶこと）。群衆の一部はざわめくが、多くは聞いていない。祭りの声のほうが大きい。
2. **天城**：典膳の合図。仁科は斧を振らない。代わりに天城が、怯えきって剣を突き出す。先輩の胸に届く。
3. **座を持っていく**：対等の封は結べない（まだそこまで互いを繋ぎ留めきれていない）。座が継へ流れ始める。先輩は、流れていく座を、導管の途中で掴んで自分の中へ引き戻す。自分ごと、持っていく。「全部、私が持っていくよ」（文言は作る）。継の胸の痣が、すっと白くなる。
4. **最後の言葉**：先輩は継の腕の中で、覚え書きの言葉を、今度は自分の口で言う。八年遅れで。「君のせいじゃない」。先輩は自分の最後を、自分の言葉で語って終える。
5. **晴天**：凱旋祭の空が、ひどく晴れている。先輩の角は、崩れずに残る。継は角を抱いている。
6. **それから**：継は先輩を夜牧城の礼拝堂に葬る。三人の隣に。輪は終わった。次の魔王は生まれない。継は魔王座の最後の宿主を看取った僧侶として、街道の十二の宿駅の記録帳に、一つずつ本当のことを書いて回る。

- 解放：先輩は八年ぶん背負った座を下ろす。継は嘘を下ろす。
- 【書き方】死の瞬間は直接書かない。息、声、腕の中の重さ、角の手触りで。泣かせにいくが、湿らせすぎない。晴天の明るさで締める。

## ed07　ドハッピー・ドメリーバッド「とこよみち」（`@vis v3 night`、イメージ曲 `m1`）

- 基本：幸せなのは二人だけ。世界は本当にバッドエンド。世界の平和は幸せの勘定に一切入れない。

1. **読まない**：継は巻物を読まない。破る。先輩は角環を、自分の力で割る。
2. **捨て**：継が、自分の胸の聖印に自分から手を当てて、封を開く。座の半分を、自分から受け取る。**継は迷わない。** 八年間立ってきた足場（僧侶であること、正義の側にいること、嘘を本当にすること）を、全部まとめて捨てる。額に、小さな黒い角が二本。先輩とお揃い。
3. **夜**：二つに割れた魔王座が、二人の中で共鳴して膨れ上がる。太陽が消える。真澄国は、明けない夜に沈む。聖句が効かなくなる。大聖堂の灯が全部消える。典膳は暗闇の桟敷で、台本を手に何も見えなくなっている。
4. **千鳥**：暗い広場で、千鳥がリュートを弾き始める。他にできることがないから。緑の袖の歌。`@bgm m1` はこの一文の直前。
5. **道**：二人は、明けない夜の凱旋街道を北へ歩く。新婚旅行。宿駅ごとに寄る。記録帳は、もう誰も読まない。二人は記録帳に何も書かない。代わりに、宿駅ごとに一つ、口づけを置いていく。
6. **世界**：夜の中で国が崩れていく様子を、二人は景色として眺める。畑が枯れる、人々が灯りを奪い合う遠い声。二人の目はきらきらしている。死んでいる。
7. **口づけ**：何度も。息継ぎ、笑い声、合間の短い言葉。角と角がぶつかって、二人で笑って、また。継は息が上がったまま敬語で「先輩、これで宿駅いくつめです」と言い、先輩は数えていないと答える（【書き方】数えない。「数えていない」がこの作品の最後の答え）。
8. **締め**：夜牧城。二人は玉座には座らない。礼拝堂の、屋根の落ちたところから、星を見上げる。旋律を口ずさむ。どこにも帰らない帰り道の終わり。

- 語る者がいない世界。二人の過去を語る者も、もういない。二人も語らない。
- 着地の温度：**幸福感で終わらせない。** 明るく、きらきらして、壊れたまま終わる。
- `@bgm m1` のあと、曲は「終」のあとも、タイトル画面でも鳴り続ける（エンジンの仕様どおり）。

## ed08　世界に愛想つかし・敵ぼっこぼこ狂愛「幕引き」（`@vis v3 shatter`）

- 基本：二人の狂気的な愛の力で、敵を派手に盛大に、正面から粉砕する。ジャイアントキリング。ギャグ寄りにしない。

1. **巨像**：継が読み始める前に、典膳が聖劇の最後の仕掛けを動かす。大広場の中央の **正義の大像**（天秤を掲げた女神像。八年ごとの凱旋祭で民の歓声を吸い続けてきた聖像）が、歓声を燃料に立ち上がる。首斬りの斧の代わりに、大像の剣が刑場へ振り下ろされる。立ち向かうものがでかい。
2. **聖と闇**：継が角環の鎖を引きちぎって、先輩の角環を外す。先輩の闇が解き放たれる。継の聖句が、闇に絡む。聖と闇がばらばらのまま同じ方向を向く（【書き方】溶け合わない。二本が並んで一本の刃になる形で）。
3. **粉砕**：大像の剣を、先輩の角が受け止める。継の聖句が天秤の鎖を焼き切る。天秤の皿が落ちて、典膳の桟敷を潰す。大像は内側から砕けて、吸ってきた八年ぶんの歓声が、ただの音になって広場に降る。`@fx shake`。
4. **小物**：天城は逃げようとして、自分から聖火の噴水に落ちる（二人は追わない。見もしない）。修道院長・慈恵は桟敷の瓦礫の下から這い出してきて、継に「献げものの分際で」と言う。継は、初めて彼女に向かって生意気を言う。
