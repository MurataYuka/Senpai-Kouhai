# 冒頭の一場面（第一章の頭にそのまま使う）

夜牧城の礼拝堂は、屋根の半分が落ちていた。
崩れた梁の隙間から、夜明け前の空が覗いている。星はもう薄い。
祭壇の前に、白い布で包んだものが三つ並んでいた。
長いのが二つと、少し短いのが一つ。
その前に膝をついて、若い僧侶が祈っていた。
祈りの言葉は短かった。三人ぶん、同じ言葉を三回。
最後の一回だけ、途中で途切れて、しばらく続きが来なかった。

{name}は、入り口の柱にもたれてそれを見ていた。
頭の両側から、羊のそれに似た黒い角が大きく巻いている。巻きの根元には聖銀の輪がひとつずつ嵌められ、細い鎖が首の後ろで二つの輪を繋いでいた。
鎖は、身じろぎするたびに小さく鳴った。
その音で、僧侶の肩がわずかに強張る。

▷祈りが短いね、と{name}は言った。三人ぶんにしては。

「長ければ届くというものでもありませんので」

僧侶は振り向かずに答えて、立ち上がった。
法衣の裾についた灰を払う。細い金縁の眼鏡の奥で、目がこちらを見る。
見るのは顔だけだった。角のあるあたりへは、決して視線を上げない。

白洲継。
{name}が最後に会ったとき、この子はまだ背丈が胸にも届かなかった。
今は、見上げなくていい。そのくらいには、大きくなっている。

「角環を締め直します。こちらへ」

▷行かなかったらどうなるのか、と{name}は尋ねた。

「試しますか。構いませんよ。僕から離れて困るのは、先輩のほうですから」

先輩、と彼は呼んだ。
昔と同じ呼び方だった。昔と同じ響きではなかった。

{name}が柱から背を離すと、僧侶は一歩だけ近づいて、両手を上げた。
指先が角環に触れる。角そのものには、触れないように。
短い聖句が唱えられる。聖銀が冷たく締まり、頭の芯がきしんだ。
{name}は小さく息を吐いた。

▷君は昔から手が冷たいね、と言ってみる。

「覚えていてくださって光栄です」
僧侶は手を下ろした。
「ほかのことも、そのくらい覚えていてくだされば良かったんですが」

何のことかと尋ねる前に、彼は懐から封書を取り出していた。
封蝋には、王都の典礼院の紋が押されている。
「護送の命令を確認します。……魔王を生け捕りにした場合、僧侶は縛魂の封を施し、単独にて——」

そこで、読む声が止まった。
単独にて。
封書は、戦いの前に渡されたものだった。
僧侶はしばらくその一語を見下ろしてから、何事もなかったように封書を畳んだ。

「王都までは、凱旋街道を宿駅伝いに下ります。十二の宿駅です」
「王都ではもう、凱旋祭の支度が始まっているでしょう。先輩の首を見に、国中から人が集まる」

▷それは楽しみだ、と{name}は笑った。

「……そういうところが」

僧侶は言いかけて、やめた。
代わりに、祭壇の三つの布へもう一度だけ目をやった。

▷三人を殺したのは自分ではない、と{name}はもう一度だけ言った。

「聞きました。昨日も」
僧侶は礼拝堂の出口へ歩き出す。振り返らない。
「信じる理由がありません」

鎖が鳴った。
三十歩より先へは行けない。{name}は、彼の背中を追って歩き出した。

城門の外で、夜が終わりかけていた。
丘を下っていく一本の道が、白く浮かび上がって見える。
王都へ続く道。
帰り道だった。
