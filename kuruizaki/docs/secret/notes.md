## 章ごとのメモ

### 第一章（十一年目 霜月三日）6513字／継ぎ目1箇所点検、修正0件
- 冒頭は設計書どおり（@fx の名前だけ記号に置き換え、黒色火薬の最初の一発に f2 を足した）。
- 戦闘：一隻目の砲塔四基→六隻目（最後尾、補給車を鎖で引いて南へ戻ろうとしていた）を先に一基→二隻目・三隻目の間（履帯の軸を割り、ほどけた履帯で左の艦の銃眼を潰す／傾いた砲塔どうしが噛み合い、二基同時）→四隻目（乗員が自分で逃げる）→五隻目（三基）→六隻目の補給車の水の樽を先に鳴らす→残りの砲塔→機関部を最後に六つ。
- 鉄治の数：砲塔二十一基（先輩は「二十二」と言う。数えていない）。
- 宝物の箱：角の塗りが剥げた菓子の空き箱（ブリキ）。十一年ぶん、一日一つ。ぎっしり。
- 今日の一番：青と金に焼けた、一度くるりとねじれた欠片（c1 の分岐の中で完結。以降触れない）。
- 灰野第三塹壕：亜竜七、鱗人三、獣人四。固いパンと薄い豆の汁。灰野の賭けは「明日の天気」だけ（胴元が立たない）。
- 左目の傷：最初に爆を出したとき自分で切ったと思っている。触ると少し冷たい（凍傷の痕の伏線）。
- 翼：左が大きい、右は煤色、左は茜色。指が一本通るくらいの穴、縁が焼いたように硬い。風が穴を抜けて笛のように鳴る。
- 高いところが好き（壊した艦の煙突に登る）。
- 真竜の航空隊は灰野の上で高さを落とさない。「上からは戦場が地図に見える」（鱗人の古参）。
- 鉄治：隻腕。紙の端に小石二つ。上申書は二枚書き、一枚を送り、一枚を古い弾薬箱に（却下で戻った原本と控えを重ねている。何百枚）。
- 司令部から「灰野の亜竜の軍歴を寄越せ」の照会（戦果ではなく軍歴だけ）。高雲居の坊ちゃん（鷲尾）が前線の指揮をやりたがっている噂。
- r10 解放。
- 独白：霜ヶ峰の航空参謀室。名簿の四枚目ではなく三枚目の下から二行目。灰野の上申は十一年で千と少し、すべて却下。配置案「後方、第二資材置き場。任務、土嚢積み」。手帳の「今夜の一行」を読む（何の手帳かは書いていない）。
- 状態：v1 なし、v5=1→3（独白）。

### 第二章（霜月十日〜十四日）6427字／継ぎ目2箇所点検、修正0件
- 命令書：「長期の前線勤務につき、後方にて休養ならびに再訓練を命ず。赴任先、霜ヶ峰前線基地」。裏は白紙。
- 鷲尾：三頭で降りてくる。白い軍服、金の飾り緒、首の付け根に青い鱗三枚。外套を部下に敷かせて歩く。「亜竜ごときが、よく十一年も生き残ったものだ」。軍歴を読み上げる「戦果記録、なし」「天議の温情」。先輩「運がいいので」「灰は払えば落ちますよ、長靴の」。
- 鉄治「……俺が、上申しとく」「全部だ」（→ r11 の異議、第八章で解放）。
- 送別の宴：乾かした木の実と、くすねた砂糖で寝かせた手製の酒（三年もの、焦げた匂い、まずい）。灰野の歌は麦の歌。
- 砂里が自分の上着を貸す（袖が短い）。朝、固いパンの包み三日ぶん（一週間かけて）。
- 鉄治の束：握りこぶし二つ重ねたくらいの束が、何本も。「紙のほうが、勝手に誰かを探す」。
- 六年目の夏：七隻の日、鉄治が左腕を失い、先輩が担いで走った。r06 解放。
- 送別の一度咲き：平原の真ん中から、掌で包んだ熱を真上へ。光→三つ数えて音。鱗人の古参が帽子を取る。**v1=1**。
