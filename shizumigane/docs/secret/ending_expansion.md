# エンディング拡張 裏設計書

結夏に見せてはいけない資料。`secret_design.md` の「8. エンディング」を、この資料の内容で置き換える（ノーマル・バッド二種は変更なし）。

---

## 0. 結夏の感想と今回の方針（零壱用）

- 一番刺さったのはメリバ（主人公主体）「居残り」。透が主人公の狂気に飲まれて、十二年分の重圧から自分を解放してしまった感じが良かった。
- 要望：
  - トゥルーとメリバ二種を、それぞれ本編の一章の半分くらいの長さにする。見比べたときに、転落の深さと幸せの深さが互いを引き立てるように。
  - メリバは湿度を高く、描写を濃く。どろどろの激重感情と、異常に近い距離感。平たく言えば狂気のヤンデレ。「エロではないのに、いっそエロく見える」くらいの密度。
  - トゥルーは傷が残りつつ、正常な判断が効いている静かな幸せ。
- 三本の対比の軸：「名前を呼ぶ／返事をする」を、トゥルーでは**まだしない**、メリバ主人公主体では**主人公が呼ばせ続ける（透が返事をし続ける）**、メリバ後輩主体では**透が呼び続ける（主人公に返事をさせ続ける）**。

## 1. 長さの目安

- Claude Code は ch01〜ch10 の本文の文字数を数え、一章の平均を出す。拡張する三つのエンディングは、それぞれその45〜55%に収める。
- どのエンディングも、場面を5〜7つに分ける。場面の間に短い暗転を入れ、急がせない。
- 選択肢は入れない（浸るためのパートなので）。ただしメリバ二種には、結果が変わらない「▷」の選択肢を一か所ずつ入れてよい（下記）。

## 2. 湿度の書き方（メリバ二種共通）

- 性的な行為・裸・性的な部位の描写はしない。**その手前の、触れている場所と、息と、声と、水と、体温**で密度を出す。
- 触れる場所は手首、喉、首筋、耳、額、濡れた髪、指先、膝。脈や声の振動を指で感じる描写を多用する。
- 距離は常に近すぎる。息がかかる、額がつく、同じ机に二人で座る、一枚のカーテンにくるまる。
- 水：濡れたシャツの冷たさ、髪から落ちる雫、水面に映る二人、窓の外の水。すべて「二人以外は水の向こう」という閉鎖感に使う。
- 地の文で感情を説明しすぎない。行為と台詞で重さを出す。狂気は穏やかな口調のまま進める（叫ばない狂気）。
- 透の生意気は最後まで残す。敬語も「先輩」呼びも崩さない。敬語のまま、言っている中身だけが異常、という温度にする。
- 眼鏡を外すことに意味は持たせない（前作と被るため）。眼鏡は曇る、ずれる、指で直される、くらいに使う。

## 3. メリバ（主人公主体）「居残り」 拡張

主人公の狂気が主。透はそれに飲まれ、飲まれることで救われてしまう。主人公は自分がしていることを分かっている。分かったうえで、選ぶ。

### 場面1 二度目の鐘
- 透が名前を呼ばれて返事をした直後。透の手は主人公の手の中にある。
- 主人公が振鈴を拾う。透はそれを見て、何をするつもりか分かる。止めない。止めようとして上げた手が、振鈴ではなく主人公の袖を掴む。
- 鐘。水位が一気に上がる。捜索隊の光が、体育館の外で止まる。もう入ってこない。透は主人公に見つかっているから。
- 遠くで、現実の側から名前を呼ぶ声がする（生存者がいれば、その人たちの声。いなければ榊の娘の声のような、知らない子どもの声）。主人公は返事をしない。透の耳を両手で塞ぐ。透は主人公の耳を塞ぎ返す。額がつく距離で、互いの声だけが聞こえる。

### 場面2 放課後の教室
- 二階の四年教室。時計は十二時のまま。窓の外は、窓枠のすぐ下まで水。
- 二人とも濡れている。透が首のタオル（第一章冒頭で首にかけていたもの）で主人公の髪を拭く。手つきは乱暴で、途中から丁寧になり、最後は止まる。
- 透「……風邪ひきますよ。ここ、たぶん風邪とかないですけど」
- 透の眼鏡が曇る。主人公が袖で拭いてやる。拭いている間、透は近視で見えないので顔を寄せてくる。拭き終わっても離れない。「見えないので」と言い張る。見えている。

### 場面3 出席
- 教卓に出席簿がある（演出の出席簿と同じもの）。調査隊七人の名前。
- 主人公が、自分と透以外の名前に、自分の手で線を引いていく。生きている者の名前にも。透は見ている。
- 透「……森岡、生きてますよ」（生存者に合わせて変える。大吾が死んでいれば、生きている者の苗字で。誰も生きていなければ「……助教の娘さん、まだ小さいですよ」と、榊の名前に線を引いた瞬間に言う）
- ▷ 選択肢（結果は同じ）：「知ってる」と答える ／ 何も言わずに次の名前に線を引く。
- 透は少し黙ってから、笑う。十二年分、一度も笑わなかった種類の笑い方で。「そうですか。……そうですよね」
- 主人公が出席をとる。透の名前を呼ぶ。透「はい」。もう一度。「はい」。何度も。透の声は回を追うごとに柔らかくなる。
- 主人公は透の喉に指を当て、「はい」のたびに声の震えを指で確かめる。

### 場面4 解放
- 並んで座った子ども用の机（一つの机に二人）。膝がつく。
- 透が話す。ここに来てから、陽太の声が聞こえなくなったこと。さよ子さんの「ありがとう」を、もう聞かなくていいこと。研究室も、論文も、湛水も、もう関係ないこと。
- 透「僕、ずっと、誰かに謝らなきゃいけないと思って生きてたんです。……ここ、謝る相手、先輩しかいないんですね」
- 透「楽です。すごく。……最低でしょう」（本編第七章の「最低でしょう」を反転させた使い方。本編では自己嫌悪、ここでは安堵）
- 主人公は、それでいい、という意味のことを言う（▷）。

### 場面5 返事をしない
- 主人公が一度だけ、わざと返事をしない場面を作る。透が主人公を「先輩」と呼ぶ。主人公は教室の暗がりで黙っている。
- 透がだんだん取り乱していく。敬語が崩れかける（崩れきらない）。「先輩。……先輩、どこですか。冗談やめてください。……先輩」
- 最後に主人公が返事をする。透は主人公の手首を掴んで、しばらく離さない。脈を指で確かめている。
- 透「……二度としないでください。呼んだら、返事してください。一回で」
- これ以降、透は主人公が視界から消えることを許さなくなる。主人公はそれを望んでいた。地の文でそれを一行だけ示す（例：「そうなるように、した」）。

### 場面6 カーテン
- 冷えてくる。暗幕のカーテンを外して、二人でくるまる。
- 濡れたシャツ越しの体温。透の心臓の音。透の息が首筋にかかる。透はずっと主人公の名前を呼ばない。呼ぶのは主人公だけ。透は返事をするだけ。
- 透「先輩、もう一回呼んでください」。主人公が呼ぶ。透「はい」。その繰り返しで眠りに落ちる（向こうに眠りはないはずなのに）。

### 場面7 湖
- 現実。九月の末。鐘ヶ淵ダム湖。水面の下に校舎の屋根。
- 岸に「行方不明者の情報を求めています」の立て看板。二人の名前（主人公の名前は差し込み）。
- 生存者がいれば、その人が岸に立って二人の名前を呼ぶ。いなければ、看板だけ。
- 水の底。四年教室。
- 最後の数行：主人公が透の名前を呼ぶ。透「はい」。——水面の上で誰かが主人公の名前を呼んでいる。主人公は返事をしない。透の耳を塞ぐ。
- 最終行は透の声で「先輩、これ、居残りですよ」。主人公の返事は書かない。画面が水で満ちて終わる。

## 4. メリバ（後輩主体）「ずっといっしょ」 拡張

透の狂気が主。十二年間返事をしなかった少年が、返事をしてくれる人を手に入れて、二度と手放さない。主人公は透に見つかった側で、透のもの。

### 場面1 舞台の下
- 透が陽太に返事をし、主人公の手を引いて点検口から舞台の下へ降りる。膝下まで水。真っ暗。懐中電灯は一本。
- 透が懐中電灯を消す。「見えなくていいです。先輩は、声で分かるので」

### 場面2 紹介
- 暗闇の奥に、子どもの気配。透がそちらへ話しかける。十二年ぶりに、陽太に。
- 透「陽太。……ごめん。遅くなった。こっち、先輩。僕の先輩」
- 「僕の」を二回言う。二回目は主人公に向けて。
- 子どもの声が「とおるくんのせんぱい」と繰り返す。透はそれを聞いて、嬉しそうにする。

### 場面3 点呼
- 透が主人公の名前を呼ぶ（本編で一度も呼ばなかった下の名前を、ここでは何度も呼ぶ）。主人公が返事をする。
- 返事が一拍遅れると、透の手が主人公の手首を探す。見つけると脈を押さえる。「……いますね」
- 透「僕、あのとき返事しなかったんです。だから、先輩は、ちゃんと返事してください。僕が呼んだら、全部」
- ▷ 選択肢（結果は同じ）：「うん」と答える ／ 黙って、透の手を握り返す（→透はそれを返事と認めず、もう一度名前を呼ぶ。返事をするまで呼ぶ）。

### 場面4 他の声
- 舞台の上、体育館のほうから、捜索隊や生存者の声が主人公の名前を呼ぶ。
- 透が主人公の耳元に口を寄せ、上から自分の声で主人公の名前を重ねて呼ぶ。他の声が聞こえなくなるまで。息が耳にかかる。
- 透「先輩の名前、もう僕以外の声で聞かなくていいです。……聞かないでください」
- 敬語のまま命令になっている。透はそれに気づいていない。

### 場面5 返事の対価
- 透が、主人公が返事をするたびに額に額をつけて「ありがとうございます」と言う。律儀に、毎回。さよ子が十二年言い続けた「ありがとう」を、透が主人公に言い続ける構図（地の文では説明しない）。
- 透「先輩が返事するたびに、僕、ちょっとずつ許される気がするんです。……だから、ずっと呼びます。ずっと返事してください」
- 濡れた前髪、眼鏡の縁が主人公の頬に当たる冷たさ。透の指が主人公の喉に触れて、返事の振動を確かめる（「居残り」では主人公が透の喉に触れる。ここでは逆）。

### 場面6 三人
- 水が上がってくる。胸まで。透は慌てない。主人公を抱えるように後ろから腕を回す。
- 暗闇の奥で、子どもの声が「ずっといっしょ」と歌うように言う。透がそれに合わせて、同じ言葉を主人公の耳元で言う。
- 透「先輩。……先輩は、僕に見つかったんですよ。忘れないでくださいね」

### 場面7 湖
- 現実。捜索は十日で打ち切られる。体育館は沈む。
- ダム湖の水面。
- 最終行：湖の底から、子どもの声と大人の男の声で「ずっといっしょ」。そのあとに、男の声だけで、主人公の名前（差し込み）。返事の「はい」を主人公の声で。画面が暗くなって終わる。

## 5. トゥルー「みつけた」 拡張

静かな幸せ。傷は残る。正常な判断が効いている。メリバ二種と見比べたとき、「この二人は踏みとどまった」と分かるように、メリバで出てくる要素（名前を呼ぶ、返事、耳を塞ぐ、喉に触れる）を、ここでは健全な形か、まだしない形で出す。

### 場面1 みつけた
- 本編どおり（透が陽太の名前を呼び、「はい」と返事がある）。ここは短くせず、透の十二年ぶりの呼び声を丁寧に書く。透の声がかすれて、一度で出ず、二度目で出る。

### 場面2 朝
- 現実の昇降口で目覚める。生存者それぞれの様子。透は主人公の袖を掴んだまま目を覚ます。気づいて放す。放してから、もう一度掴む。
- 九月一日。ゲートが閉じる音が谷に響く。

### 場面3 収容と葬儀
- 警察。舞台下から陽太が収容される（描写は本編の線引きどおり）。
- 榊の葬儀。榊の幼い娘。透がその子に話しかけられて固まる。主人公が隣にいる。榊の件は、生存者が一生背負うものとして書く。

### 場面4 さよ子
- 本編どおり（「知ってたよ」「十二年、ありがとうね」）。ここを一番丁寧に書く。
- さよ子の家を出たあと、透は団地の階段で座り込む。主人公は隣に座る。何も言わない。透は泣かない。泣かないまま、主人公の肩に額をつける。長い時間。

### 場面5 研究室
- 秋。研究室。生存者が戻ってくる。
- 透が、生存者の一人を初めて下の名前で呼ぶ（大吾が生存していれば「大吾」、していなければ千景かあゆみ、誰もいなければ榊の娘に手紙で）。呼ばれた側が驚き、透は「……何ですか。呼んだだけです」と生意気に返す。
- 実測図の完成。第一章の「先輩がいなくなったら、実測図が埋まらないので」の回収。完成した図面を二人で見る。沈んだ校舎の、最後の記録。

### 場面6 湖の岸
- 本編のラスト（「呼んだら、先輩、返事するでしょう。そしたら先輩は僕に見つかるんですよ。いいんですか」）へつなぐ。
- その直前に一つ足す：透が「あっちで、先輩が僕の名前呼んだの、ちゃんと覚えてます」と言う。「……呼ばれて返事するの、怖くなかったんです。初めて」
- 主人公の返事（▷）のあと、透は名前を呼ばない。代わりに「先輩」と呼び、いつもの調子で生意気なことを一言言って、帰り道を歩き出す。主人公の袖を掴んだまま。
- 最終行は静かに。水面が秋の光を返す。

## 6. 演出の追加

- 水位：トゥルーは場面2で水の表示が引き始め、場面6で消える。メリバ二種は場面ごとに上がり、最終場面で画面を満たす。
- 出席簿の状態欄：
  - 「居残り」場面3で、主人公が線を引くのに合わせて、状態欄の名前にも一本ずつ線が入る（朱の「欠」ではなく、黒い鉛筆の線）。最後に残るのは二人の名前だけ。
  - 「ずっといっしょ」では、状態欄の主人公の名前の横に、小さく「水無瀬」と書き込まれる（所有の表示）。場面3で入れる。
  - トゥルーでは、場面5で透の名前の欄の「欠」ではない空白に、「出」の印が一つ押される。
- メリバの台詞：名前を呼ぶ台詞は、捜索隊の呼び声と同じ「滲んで出る」演出を**使わない**。はっきり、近く、少し大きい文字で出す。距離の近さを文字の大きさで表す。
- 音（ONのとき）：メリバの最終場面で鐘が一度、水の中のようにくぐもって鳴る。トゥルーの最終場面では鐘を鳴らさない。
