# エンディング拡張の文字数メモ（ネタバレ注意・結夏に見せない）

計測は `node tests/count.js [基準値]`。

## 数え方
- 章の文字数：その章のシーンに書かれた表示文（地の文・台詞・選択肢の文言）の合計。全分岐・途中デッドエンドを含む。
  書式記号（先頭の `! ~ @ +`、`[[ ]]`）・改行・空白・区切り `---` は数えない。`{n}` は既定名「真澄」（2字）で数える。
- エンディングの文字数：routes.json のモデルルートを流し、最後の分岐（end_01・end_05 は q18、end_06 は q19）を選んだ直後から
  終わりまでに実際に表示される文。生存者によって一部の行が変わるので、モデルルート上の値とする
  （end_01＝ルート1〔千景・大吾・あゆみ生存〕、end_05＝ルート3〔あゆみのみ生存〕、end_06＝ルート4〔大吾・あゆみ生存〕）。
