# 後日談

## 仕組み
- タイトルの「後日談」ボタン（id t-af）：記録に e1 があるときだけ表示（?debug=1 は常時）。前回の名前を入力欄に入れておく（localStorage snw_name）。
- G.mode = 'af'。body に af クラス（背景を少し明るく、錆朱を苔色に、x-a でも枠は消さない）。
- 章キーは 'a1'〜'a4'、シーンは af{章}_s{番号}、フラグは aflag_NN。
- 初期状態は after1.js の SNW.afterInit（s01 左手の温度／s03 白＋x-a／s02 右耳／s04 夜目 を最初から持つ）。
- パラメータ：a1 = heart（綴の素直さ、初期50、0〜100）／a2 = 枠の段階（0〜3）
- 枠：二本の糸（t-a 生成り寄り＝主人公、t-b 苔寄り＝綴）。a2：0 平行／0〜1 近づく／1〜2 綴側がほつれて切れかける／2〜3 縒り合わさって一本の紐。
- 演出：fx:'twine'（from, to, ms, back=true で行って戻る）／fx:'glow'（一瞬光って枠が消えたように見える。最終場面用）
- 右耳：綴の右から話す選択肢は need:!s02 → 「（届かない）」で選べない。
