# 白縄村ADV 制作指示書（Claude Code用）

このフォルダは、選択肢型テキストADV『しらなわ』（仮題）の制作プロジェクトです。
依頼主は結夏（ゆか）。シナリオと裏設定は零壱が設計済みで、`docs/secret/裏設計書.md` にあります。

## 最重要：ネタバレ防止ルール

結夏はこのゲームのプレイヤーです。本人に物語の中身を知らせないことが、このプロジェクトの成否そのものです。

- 作業開始時に必ず `docs/secret/裏設計書.md` を読み、シナリオ判断はすべてそれに従って自分で決める。結夏にシナリオ上の相談をしない。
- 結夏への返答・進捗報告では、ストーリー・登場人物の秘密・展開・エンディングに一切触れない。報告は「第N章まで遊べる」「セーブ機能を追加した」など技術的事実だけにする。
- コミットメッセージ、ファイル名、関数名、変数名、HTMLに出るid/classにも内容が推測できる語を使わない。シーンやフラグは `ch3_s2`、`flag_07` のような番号で管理し、対応表は `docs/secret/` 内に置く。
- 結夏から聞いてよいのは、UI・操作感・文字の読みやすさ・遊んだ感想など、プレイヤーとして答えられることだけ。
- 結夏が明示的に「ネタバレOK」と言うまで、このルールは解除しない。

## 表の設定（結夏も知っている範囲）

- 舞台：平成元年、改元の年の夏の終わり。山あいの「白縄村（しらなわむら）」。町までバスで一時間半、バスは一日三本。電話は黒電話か商店前の公衆電話。
- 主人公：先輩ちゃん（名前入力・21歳・大学3年）。背が高く、余裕のある美人。亡くなった母方の祖母の空き家に、管理を兼ねて移り住む。町の大学へバス通学。
- 芦原 綴（あしはら つづる）：20歳・大学2年・眼鏡。白縄村生まれ。同じ大学に通うが、どれだけ遅くなっても必ず最終バスで村に帰る。
- ジャンル：因習村脱出ホラー。段階的にクトゥルフ級まで怖くなる。二人は初対面から始まる相棒で、恋人にはならない。
- 形式：選択肢型テキストADV。グラフィックなし、テキストと演出のみ。全七章程度、マルチエンディング。

## 文体ルール

- 地の文は主人公視点だが、主人公を「私」「彼女」と書かない。主語を省いた三人称寄りの語りにする。
- 主人公の発言はカギカッコで書かない。必ず `▷` から始まる間接話法の一文で書く。例：`▷ 本、逆さまじゃない？ と真顔で指さしてみせた。`
- 主人公の名前（入力値）は地の文ではほぼ使わない。呼ばれる場面でのみ使う。綴は常に「先輩」と呼ぶ。
- 詳細な文体・キャラの書き方は裏設計書に従う。

## トーン見本（第一章冒頭。この場面はこのまま使う）

```
バスが去ると、音が全部なくなった。
一日三本の最終便。降りたのは自分と、後ろの席で最後まで本から顔を上げなかった青年だけだった。

青年はそのまま帰らず、トタン屋根の待合小屋のベンチに腰を下ろした。家に着くのを一分でも遅らせたい人間の座り方だった。膝の上の文庫本は『ツァラトゥストラかく語りき』。眼鏡のレンズに、夕方の山が小さく映っている。

「……その荷物。引っ越してきた人ですか」

ページをめくる音のほうが、声より大きかった。

「悪いことは言いません。明日の朝のバスで帰ったほうがいいですよ。まあ、帰れるならの話ですけど」

▶ どうする？
　・からかう
　・素直に道を尋ねる
　・黙って隣に座る

（「からかう」を選択）
▷ 本、逆さまじゃない？ と真顔で指さしてみせた。

青年の手が一瞬止まる。それから、ものすごく不本意そうに本の天地を確かめた。
逆さまではない。

「……逆さまじゃないです」

眼鏡を押し上げかけた指が、途中で止まった。視線が、こちらの手元の紙袋に落ちている。町の大学の、生協の袋。

「それ。うちの大学のですよね」

▷ 三年だよ、と袋を軽く揺らしてみせた。

「三年」
眼鏡の奥で、心底面倒くさそうに目が細まる。
「……じゃあ、先輩ですか。最悪だ。明日から同じバスじゃないですか」
```

他の二つの選択肢の分岐も、合流先（先輩呼びの場面）を保ったまま書くこと。

## 技術仕様

- ブラウザで `index.html` をダブルクリックして遊べること（file:// で動作）。ES Modules は file:// で動かないため、通常の `<script>` 読み込みで構成する。外部ライブラリ不要、素のHTML/CSS/JS。
- 構成例：`index.html` / `css/style.css` / `js/engine.js` / `js/scenario/ch1.js` 〜 `ch7.js` / `docs/secret/`
- シナリオはJSのデータとして書く。命令の種類：地の文、台詞（話者付き）、主人公の間接話法（▷）、選択肢、条件分岐、パラメータ変更、状態異常の付与、演出、章移動。
- 機能
  - タイトル画面、名前入力（未入力時の既定値あり）
  - クリック／Enter／スペースで送り、文字送り速度の設定
  - 選択肢。条件を満たさない選択肢は、理由の一言とともに選べない状態で表示できるようにする（状態異常で行動が制限される演出に使う）
  - 状態欄：主人公と綴の「失われた感覚」を一覧表示。名称は裏設計書に従い、獲得するまでは欄自体を出さない
  - バックログ
  - セーブ／ロード（localStorage、3スロット＋オートセーブ）。localStorage は try/catch で囲み、使えない環境でも遊べること
  - 既読スキップ
  - ゲームオーバー時は直前の選択肢からやり直せる
  - クリア済みエンディングの記録
  - デバッグ用の章ジャンプは `?debug=1` のときだけ表示する（結夏が偶然見ないように）

## ビジュアル方針

- 主役は「縄」。テキスト窓の縁を一本の白い縄として描き（SVGかCSS）、物語の進行に合わせてほつれていく。派手さはここ一点に使い、他は静かに抑える。
- 色：湿った杉林の夜 `#1E2426`、生成りの文字 `#E6E1D3`、縄の白 `#F2F0EA`（多用しない）、錆朱 `#8C3B2E`（ごく一部）、苔 `#5B6B55`。
- 書体：Shippori Mincho（Google Fonts）＋游明朝・ヒラギノ明朝・serif のフォールバック。本文は行間広め、一行40字前後。
- 動きは最小限。怖い場面でだけ、文字の滲み・一瞬の欠け・画面の揺れなどを使う。`prefers-reduced-motion` を尊重する。
- 状態異常の一部はUIそのものに影響させる演出がある（詳細は裏設計書）。
- スマホ幅でも読めること。

## 作業の進め方

1. `docs/secret/裏設計書.md` を読む。
2. エンジン一式と第一章を作る。結夏に「第一章まで遊べる」とだけ伝え、操作感の感想をもらう。
3. 感想を反映しつつ、第二章以降を一章ずつ追加する。各章の完成時に通しでテストし、報告は技術的事実のみ。
4. 全章完成後、全エンディングへの到達をテストする。
