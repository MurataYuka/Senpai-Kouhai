# 闇市ADV 制作指示書（Claude Code用）

このフォルダは、選択肢型テキストADV『くもりがらす』（仮題）の制作プロジェクトです。
依頼主は結夏（ゆか）。シナリオと裏設定は零壱が設計済みで、`docs/secret/裏設計書.md` にあります。

## 最重要：ネタバレ防止ルール

結夏はこのゲームのプレイヤーです。本人に物語の中身を知らせないことが、このプロジェクトの成否そのものです。

- 作業開始時に必ず `docs/secret/裏設計書.md` を読み、シナリオ判断はすべてそれに従って自分で決める。結夏にシナリオ上の相談をしない。
- 結夏への返答・進捗報告では、ストーリー・登場人物の秘密・展開・エンディング・伏線に一切触れない。報告は「第N章まで遊べる」「セーブ機能を追加した」など技術的事実だけにする。
- コミットメッセージ、ファイル名、関数名、変数名、HTMLに出る id / class、CSSのクラス名、コメントにも、内容が推測できる語を使わない。シーンやフラグは `ch3_s2`、`flag_07` のような番号で管理し、対応表は `docs/secret/mapping.md` に置く。
- 数値やフラグの名前も番号で管理する（`v1`、`v2` など）。
- デバッグ用の章ジャンプ・フラグ表示は、URLに `?debug=1` を付けたときだけ有効にする。通常起動時には存在が分からないようにする。
- 結夏から聞いてよいのは、UI・操作感・文字の読みやすさ・遊んだ感想など、プレイヤーとして答えられることだけ。
- 結夏が明示的に「ネタバレOK」と言うまで、このルールは解除しない。

## 表の設定（結夏も知っている範囲）

- 舞台：昭和二十二年、十一月の終わり。港町・潮見の駅前に広がる闇市。
- 主人公：先輩（名前入力・24歳）。背が高く、余裕のある美人。元タイピストで字がきれい。空襲で両親を亡くし、家族は南方から復員した兄・清孝だけ。兄から「真砂堂気付」で手紙は届くのに、本人は帰ってこない。「潮見に来てくれ」という手紙を受け取って町に来る。
- 識（さとる）：20歳・銀縁眼鏡。市場の奥の修理屋「真砂堂」で時計と眼鏡の修理見習いをしている。店には二年いる年下の古参。年上の新入りである主人公を、皮肉まじりに「先輩」と呼ぶ。敬語は崩さない。
- ジャンル：ヒトコワサスペンスホラー。怪異は出ない。二人は初対面から始まる相棒で、恋愛寄り。
- 形式：選択肢型テキストADV。グラフィックなし、テキストと演出のみ。全十章、マルチエンディング。

## 文体ルール

- 地の文は主人公視点だが、主人公を「私」「彼女」と書かない。主語を省いた語りにする。
- 主人公の発言はカギカッコで書かない。必ず行頭を ▷ にした間接話法の一文にする（例：▷ 兄に会うまでは帰らない、と答えた。）。選択肢の文言も同じ形にする。
- 主人公の名前は地の文にも出さない。名前入力で得た名前は、裏設計書で指定された場面でだけ使う。
- 時代に合わない語（カタカナの外来語の多用、現代的な言い回し）を避ける。進駐軍由来の語は時代相応ならよい。
- 性的な描写は書かない。
- 冒頭場面は裏設計書の「9. 冒頭」の文章をそのまま使う。

## 技術仕様

- HTML / CSS / JavaScript のみ。ビルド不要で、`index.html` をブラウザで開けば遊べること。外部ライブラリは使わない（フォントは Google Fonts の明朝体を読み込み、読めないときは端末の明朝体にフォールバック）。
- シナリオはデータとエンジンを分ける。シナリオは `js/scenario/ch01.js` 〜 `ch10.js`、エンディングは `js/scenario/end.js` に置く。
- 機能：名前入力、クリック／Enter／スペースで文字送り、既読スキップ、オート、バックログ、セーブ／ロード（複数スロット、localStorage）、文字速度・文字サイズの設定、タイトルへ戻る。
- セーブスロットには章番号と日時だけを表示する（章タイトルは表示してよい）。
- エンディング回収状況をタイトル画面から見られるようにする。未回収のエンディングは名前を伏せる。
- スマホ幅でも遊べるレイアウトにする。

## ビジュアル方針

- 基調：夜の闇市。煤けた墨色の背景、裸電球の琥珀色、雨の青灰色。
- テキスト枠は曇り硝子をイメージしたもの。枠と背景の演出の詳細は裏設計書の「10. ビジュアル演出」に従う。
- 文字は明朝体、行間は広め。読みやすさを最優先にする。
- 効果音・BGMは入れない（結夏は自分で環境音を流して遊ぶ）。

## 作業の進め方

1. `docs/secret/裏設計書.md` を読む。
2. エンジンと第一章を作り、「第一章まで遊べる」とだけ報告する。
3. 結夏から操作感などの感想をもらったら反映し、一章ずつ追加する。報告は技術的事実のみ。
4. 全章とエンディングが揃ったら、`?debug=1` で全エンディングに到達できることを自分で確認してから「完成した」と報告する。
