## 0. 一枚で言うと

令和の冬、デジタルが物を覚えていられない山奥の湯治場。客が一人ずつ、宿帳から名前ごと、人の記憶から消えていく。残るのは、本人の手で書いた紙と、到着のときに撮られたビデオテープだけ。
テープを逆さに回して頭まで巻き戻すと、取られた人は谷の外へ帰ってくる。ただし帳尻が合わされる。
先輩は、自分も覚えていない三十二年前にこの谷で一度取られ、父親に巻き戻されて帰ってきた子どもだった。父親はその帳尻として取られ、世界の誰も、先輩自身も、父親を覚えていない。
後輩は、十一歳のとき、知らない女の人が自分の名前を呼ぶテープが怖くて、その上に天気予報を録画した。それが母親の、最後の一本だった。

タイトル『まきもどし』＝巻き戻し（テープ）／取り戻し。

## 1. 世界のルール（本編で言い切るもの。エンディングの例外はすべてここに理屈を置いてある）

| 番号 | ルール | 本編で言わせる場所 |
|---|---|---|
| R1 | 谷の中では「霞（かすみ）」が覚えを食う。デジタルの記録は薄いので真っ先に食われる（写真は白、データは空）。 | 冒頭、第一章 |
| R2 | 宿帳には夜のうちに「明日の分」が勝手に書き足される。筆は誰の手もなく動き、**書かれる字はその人本人の字**。書かれた人は翌日、湯気（霞）の中で「取られる」。 | 冒頭（予告）、第二章、第五章で目撃 |
| R3 | 取られた人は、世界じゅうの覚えから消える（人の記憶、デジタル）。残るのは、**本人の手で書いた紙**と、**本人が映ったテープ**。テープを再生している間だけ、見ている人はその人を思い出す。止めると、湯気が引くように忘れていく。 | 第二章 |
| R4 | テープが死ぬと（カビ、切断、重ね撮り）、その人はもう誰にも思い出せなくなる。だから日下部はツメを折る（上書き禁止）。 | 第三章、第十章 |
| R5 | 取られた人のテープを谷の中で再生すると、その人が「映りの姿」で宿の中を歩く（走査線の縁、音が少し遅れる）。強く覚えている者が見ていると、こちらを向き、言葉を返すこともある。 | 第四章（歩く）、第八章（文吉に向く）で前置き、第十三章で本格的に |
| R6 | 谷を出ると、谷にいた間の覚えは霞に置いていく（常連が毎年「初めて」と言う理由）。ただし**その頃のテープを見ている間は戻る**。 | 第三章 |
| R7 | **まきもどし**：取られた人のテープを、谷の中で、逆さの再生で画を出したまま頭（最初に映ったところ）まで巻き戻すと、その人は谷の外、終点のバス停に帰ってくる。谷にいた間のことは覚えていない。これには逆再生で画が出る改造デッキが要る（普通のデッキの巻き戻しは画が出ないので効かない）。 | 第七章で兆し、第十一章で全容 |
| R8 | **帳尻**：一人帰ると、帳尻として**谷の中で最後にテープに撮られた生きている者**がその場で取られる。 | 第十一章（父の伝言） |
| R9 | 宿帳に書かれた人でも、**誰かが一晩じゅう途切れずに撮り続けていれば**、霞は手が出せず、明け方にその行には線が引かれて消える。 | 第八章で文吉が言う、第九章で実行 |
| R10 | 源泉の奥の、いちばん霞の濃いところへ自分から入る者は、明日の分を待たずに取られる。 | 第一章で禁止として、第十四章で苑が実行 |
| R11 | 帳屋の初代の書き付け：「此の帳、谷に書かせるもの也。帳場の者が締むれば、谷は書かず。谷より出すべからず、出せば出た先を書く。一人帰れば一人書く。帳尻合わざれば、谷は帳を失う」 | 第十一章（記録 r09） |

### エンディングとルールの対応（例外の確認）
- ED1：R11「締むれば谷は書かず」を使う。締めた後は谷は覚えも取らないので、谷を出ても忘れない（R6 の例外。第十一章の書き付けの読み解きで、日下部に「締めたら、霞は帳を通して食べているので、食べられなくなるはずです」と一言言わせる）。締めた後は R7 の巻き戻しも効かない（帳尻を合わせる帳がないため）。
- ED2：R4 を自分から使う（重ね撮りで全部消す）。R9 で二人は互いを撮り続けて取られない。
- ED3：R5 を使う（映りの姿の先輩を、再生し続けて留める）。
- ED4：R4（重ね撮り）。
- ED5：R6（谷を出た先輩は忘れる。テープで戻る）。
- ED6：R10。
- ed07：R11「出せば出た先を書く」＋ R9。
- ed08：R11「帳尻合わざれば、谷は帳を失う」。

## 2. 舞台

- **時代**：令和八年の冬。十二月二十日に主人公が着き、本編はおよそ二週間（年越しをまたぐ）。
- **霞ノ谷（かすみのたに）と霞ノ湯**：山奥の湯治場。硫黄と鉄の匂いの湯。源泉の湯は本当に体に効き、常連の年寄りが多い。谷全体に湯気と霧が溜まり、晴れていても遠くが白い。
- **帳屋（とばりや）**：谷に一軒だけの宿。古い木造三階建て。玄関を上がってすぐ左が帳場（黒電話、ブラウン管、デッキ三台、年代順の宿帳の棚）。内湯は奥に行くほど霞が濃い。源泉は裏手の岩場、その奥は真っ白。
- **蔵**：宿の裏の土蔵。棚に何千本ものテープ（ラベルに日付と名前、手書き）。昭和六十三年から。カビ、湿気、除湿機代わりの炭。
- **谷のルール**：圏外。黒電話は外の局に繋がるが、通じても相手は「どちらの宿でしたか」と何度も訊き返す（向こうが谷を覚えていられない）。
- **終点のバス停**：傾いた標識。帰りの便は春まで無い。
- **到着の撮影の決まり**：昭和六十三年に大女将・苑が始めた。表向きの理由は「忘れないため」。

## 3. 登場人物

### 主人公（先輩）
- 名前入力（`{name}`）。苗字は作中に一度も出さない。
- 映像の修復とダビングを請け負う「巻き戻し屋」。背が高く、余裕のある美人。古い機械を見ると機嫌がよくなる。飄々としてよくからかう。
- 年齢は作中で数字にしない（三十二年前に五歳だった、という事実から自然に分かる程度）。
- **本人が知らない過去**：平成六年の冬、五歳のとき、父・惣一に連れられてこの宿に来た。父は苑に呼ばれた映像技師だった。先輩は宿帳に書かれて取られ、父が自作の改造デッキで巻き戻した。帳尻として父が取られた（父は自分を最後に撮ってから巻き戻した）。先輩は改造デッキの入ったハードケースと一緒にバス停で保護され、身寄りのない子として育った。父のことは世界の誰も覚えていない。
- ハードケースの中身（父の改造デッキ）は「拾われたときに持っていたもの」で、意味も分からないまま手放せず、それが巻き戻し屋になった理由。蓋の裏の鉛筆の線は、模様だと思っていた（父の回路図。ed08 で使う）。
- **字**：五歳のとき父に名前の書き方を教わった。先輩の字は父の字そのもの。体が覚えていたので、霞にも消せなかった。宿帳の平成六年の頁の名前は、父が娘の名前を代筆したもの。

### 後輩：日下部 環（くさかべ・たまき）
- 二十三歳。帳屋の住み込みの帳場係。谷で生まれ育った年下の古参。
- **眼鏡**：深緑のセルのウェリントン。湯気で年中曇る。外すと段差が見えない。
- 字が異常にきれい（宿帳を書くために祖母に仕込まれた）。デッキの面倒は全部この人（ヘッドの掃除、テープの切り貼り、カビ取り）。
- **生意気**：理屈っぽい強がり。理屈屋の顔をして、谷のことになると理屈を放り出す（「そういうことになっています」）。毒舌ではない。
- **癖**：撮ったテープはその場でツメを折る（上書き禁止）。一本も例外なく。
- 「先輩」の理由（表）：宿帳の上では先輩のほうが先だから。
- 「先輩」の理由（裏）：十一歳で母のテープを消してから、夜な夜な蔵のテープを見て過ごした。到着のテープの客はみんな固い顔でレンズを見るのに、平成六年の五歳の女の子だけが、レンズに向かって手を振っていた。カメラの向こうの誰か（＝あとで見る誰か）に向かって手を振ったのは、何千本の中でその子だけだった。日下部はその一本を一番多く見た。冒頭で先輩がまた手を振ったとき、頬が緩んだのはそのため。
  - 【書き方】恋愛の「ファンだった」の形にしない。子どもの日下部にとって「見ている自分に手を振ってくれた唯一の人」だった、という静かな事実として、第九章か第十章の夜に一度だけ本人の口から出させる。

#### 後輩の芯（抱えているもの）
- 母・日下部澪（みお）は、日下部が八歳の冬に取られた。日下部は母を覚えていない。
- 十一歳のとき、蔵で「母」とラベルの貼られたテープを見つけた。再生すると、知らない女の人が自分の名前を呼び、笑いかけてきた。止めると忘れる。また見ると、また知らない人が自分を知っている。それが怖くてたまらなかった。
- ある夜、そのテープに、テレビの天気予報を録画した。三倍モードで、最後まで。「明日の霞ノ谷は、雪」。
- 十五歳のとき、祖母・苑に「お前が母さんを殺した。二度と戻せない」と告げられ、帳場係にされた。ツメを折るのも、全部のテープの面倒を見るのも、そこから。
- 今も夜中に、その天気予報を見る。母の顔は一度も思い出せない。
- 【書き方】これは「悪意は小さいのに結果は最悪」。子どもの怖がりを責める書き方にしない。日下部本人も自分を責めることで立っている。救いは「許す」ことではなく、先輩が「怖かったことも、消したことも本当だ」と並べて持つこと。

### 大女将：日下部 苑（その）
- 八十四歳。帳屋の大女将。日下部の祖母。小柄で背筋が伸び、声を荒らげない。
- 夫・伊織が昭和六十三年の正月に取られた。そのときはテープがなかったので、紙（結婚前の手紙）と宿帳の一行で夫がいたことだけを知り、顔も声も思い出せなかった。それから到着の撮影を始めた。
- **欲**：伊織を巻き戻すこと。それだけ。そのためなら誰を帳尻にしてもいい。
- 平成六年、惣一を呼んで改造デッキを作らせた。伊織を巻き戻すつもりだったが、その前に惣一の娘が宿帳に書かれ、惣一は自分のデッキで娘を巻き戻し、自分を帳尻にして消えた。デッキは娘と一緒に谷の外へ。苑は三十二年、巻き戻し屋になった娘に手紙を出し続け、今年やっと来させた（手紙に「あなたの持っている改造デッキでしか再生できないテープがある」と書いた）。
- R8（帳尻＝最後に撮られた者）を知っていて、日下部には教えていない。到着の撮影を日下部にやらせてきたのは、帳尻を誰にするかの引き金を、孫の手に持たせるため。
- 【書き方】優しさの裏返しにしない。同情の余地は作らない。礼儀正しく、上品で、心の底から自分以外を勘定に入れていない。悲鳴を上げるのは第十四章の一度だけ。

### 日下部 伊織（いおり）
- 苑の夫。昭和六十三年の正月、三十一歳で取られた。蔵の奥、苑の私物の棚に、昭和六十三年の正月の家族のビデオ（障子を開けて部屋に入ってくる）がある。
- 第十三章で巻き戻されて帰ってくる。三十一歳のまま、昭和六十三年の服装で、苑を「女将さん」と呼ぶ。苑を知らない。

### 惣一（そういち）
- 先輩の父。映像技師。苗字は出さない（宿帳にあるが、読み上げる場面を作らない。先輩が「自分と同じ苗字だ」と思うだけ）。
- 平成六年のテープ（娘と到着、娘の手を持って宿帳に名前を書く）、自分で自分を撮った伝言のテープ（第十一章、記録 r08）が残る。
- 先輩の到着のテープの奥に、二人分の足跡として、再生するたびに少しずつ近づく人影として映る（R5 の弱い形。娘に一番強く覚えられたいのに、覚えられていない者の影）。

### 二階堂 文吉（ぶんきち）・トキ
- 八十歳と七十八歳の常連夫婦。毎冬来て、毎年「初めて来ました」と言う。蔵に二人の到着のテープが三十一本ある。
- トキは廊下の段差を体が覚えている（第一章の違和感）。
- 第八章でトキが取られる。文吉は目の前で妻を忘れる。
- 文吉は、トキのテープを見ている間に、平成六年の冬のことを少し思い出す（二人はその年も来ていた）。R9（一晩撮り続ければ手が出せん）は「あのときの、若い技師の人が言うとった」として文吉の口から出る。
- 以降、文吉の部屋ではトキのテープがループで流れ続け、映りの姿のトキが部屋の隅に座っている。

### 宿の人たち・客
- 芹沢 小春（せりざわ・こはる）：二十六歳の仲居。明るくてよく喋る。日下部を「たまちゃん」と呼ぶ唯一の人。字が丸い。第五章で取られる。
- 鷺沼 権造（さぎぬま・ごんぞう）：六十八歳の板前。無口。第十一章で取られる。苑が瞬きもしない。
- 早瀬 蓮（はやせ・れん）：二十八歳の動画配信者。撮れないことに苛立っている。第二章で最初に取られる。
- バスの運転手：冒頭のみ。

## 4. 三本の対比の軸

**誰が、誰を、上書きするか（重ね撮りと、ツメ）。**
- ED1（健全な形）：誰も誰も上書きしない。帳を締め、上書きでも保存でもなく、二人で次を撮る。
- ED2（主人公側の異常）：先輩が、日下部の守ってきた全部のテープを、自分で重ね撮りする。日下部にはもう先輩しか残らない。
- ED3（後輩側の異常）：日下部が、先輩のテープのツメを折り、誰にも、自分にも上書きさせず、映りの姿のまま永遠に再生し続ける。

## 5. 画面と演出

### 5-1. 常設
- `#frame`：ブラウン管の枠。角の丸い画面、四隅の暗がり、うっすらした湾曲。
- `#back`：走査線（静止）、ごく薄い砂嵐、ゆっくり降る雪（`#fxLayer` に canvas）。
- 画面の隅のビデオ表示（オンスクリーン表示）：左上にモードの記号（`@vis md`：`play`＝▶、`stop`＝■、`rec`＝●（赤く点滅、文字ではなく記号の点滅は可）、`rew`＝◀◀、`ff`＝▶▶）。右下に日付の焼き込み（`@vis dt`：作中の日付。第六章の平成六年のテープを見ている間は 1994 の日付）。
- **ラベルの帯**（章ごとに積み上がる）：画面の下辺に、テープの背ラベルの紙が一枚ずつ重ね貼りされていく（`@vis lb 1`〜`15`）。各章の頭で、その章の章題が日下部の字（端正な毛筆風の書体）で書かれたラベルが、前のラベルの上に少しずれて貼られる。古いラベルの端が下からのぞく。
  - 第十二章の最後：一番上のラベルが湯気で滲む。
  - 第十三章：一番上のラベルの字がノイズになる（`@vis nm` と連動）。
  - **第十五章の終盤（反転）**：重ね貼りされたラベルが上から一枚ずつ剥がれ落ち、一番下に、最初から貼ってあった一枚が出てくる。「平成六年十二月　{name}」。先輩と同じ字（＝父の字）。物語の間ずっと、この画面そのものが、父がラベルを書いた一本のテープだった、という反転。

### 5-2. 状態として持つ見た目（`@vis`、セーブに入る）
| 名前 | 値 | 意味 |
|---|---|---|
| md | play / stop / rec / rew / ff / off | 左上のモード表示 |
| dt | 日付文字列 / off | 右下の日付の焼き込み |
| lb | 1〜15 / peel | ラベルの帯の枚数、第十五章の剥がれ |
| fg | 0〜3 | 湯気（霞）の濃さ。テキストボックスの後ろに白い靄。3 で画面の奥がほぼ白 |
| nm | on / off | 名前のノイズ（下記） |
| sn | down / up / off | 雪の向き。up は第十四章の巻き戻しで、雪が空へ帰っていく |
| gh | on / off | 映りの姿がいる場面で、背景に走査線の濃い帯がゆっくり流れる |

### 5-3. 名前のノイズ（`@vis nm on`）
- 先輩が取られている間（第十二章の最後の数行〜第十三章で再生していない間、ED4 の最後）、本文に出る主人公の名前を、**同じ文字数の「▒」に差し替えて表示**する。灰色、静止。文字は揺らさない。
- 実装：`effects.js` の `onText` で、出たばかりの行の要素の中にある主人公の名前を差し替える（セーブや既読の文面には影響させない）。`@vis nm off` で通常に戻る（すでに出た行は戻さなくてよい）。
- 第十三章で日下部がテープを再生している間は `off`、止めると `on`。プレイヤー自身が打ち込んだ名前が、画面の上で消えたり戻ったりする。
- 【書き方】この章の本文では、名前が出る行を意図して作る（宿帳の行、テープのラベル、日下部が読もうとして読めない場面）。

### 5-4. 大きな演出（テキストボックスの後ろ）
- **第十四章の巻き戻し**：`@vis md rew`、`@vis sn up`。走査線の帯が下から上へ流れ、雪が空へ帰っていく。テキストボックスの後ろに、それまでの章の短い一行（本文から十〜十二行選ぶ。例：手を振る場面、ツメを折る音、夜通しの録画、天気予報）が、薄く、後ろの章から順に、下から上へ流れて消えていく。最後に、冒頭の「振らなくていいです」の一行が流れたところで画面が白くなる。
- **第四章**：全館のブラウン管が勝手に点く場面で、`#back` が一瞬だけ砂嵐で満ちる（`@fx`）。
