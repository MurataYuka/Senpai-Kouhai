## 章ごとのメモ

### ch01 着到（12/20〜12/21朝）
- 冒頭の一場面をそのまま頭に置いた（md：rec→stop→play→stop→rew→off）。
- 霞の間（三階の角部屋）。重いケースは開けない。「商売道具」。苑の手紙の束：毎年一通、末尾に「あなた様のお持ちのデッキでなければ、かからないテープがございます」。
- 広間：早瀬（白くなるカメラ、配信用マイク）、二階堂夫妻「初めて来ました。いいお湯だと聞いて」、トキが段差を見ずに下りる。小春「たまちゃん、またお客様撮ったの？」。鷺沼「一日十語」（日下部が数える）。
- 踊り場で早瀬と会話：「明日の朝、源泉のほう行ってみる」「俺が覚えてりゃネタになる」。
- 内湯：霞は覚えを食う、薄いものから。奥へ行くな。源泉の岩場の先は真っ白、自分から入った人は戻らない（R1・R10 の前置き）。
- c1：p2 奥を覗き、白の向こうで湯が鳴る音が近づく／p1 日下部が安心、手ぬぐいを余分に置く／p3 日下部が廊下の板の間に正座して待つ（足が痺れる）。
- 夜中：帳場で筆の音。c2：p1 耳に残る／p3 日下部「寝てます」、その声のそばで筆の音が続く／p2 戸の隙間から、筆が一本立って動くのを見る。
- 朝：向かいの部屋が空。小春「そのお部屋、昨夜はどなたも」。畳に充電ケーブル。
- 分岐で変わる事実：なし。

### ch02 再生（12/21）
- 朝食：窓際の席に湯呑みが一つ多い。小春「数え間違えたかな」→置いておく。
- 裏の源泉：白の中へ続く足跡（戻りなし）。襟留めの小型マイク（クリップ欠け）を先輩が拾う（以降は持ち物として触れない）。
- 帳場：宿帳。到着の欄（12/20 昼）と「明日の分」の頁に早瀬蓮、同じ右上がりの字。R2・R3 を日下部が説明。ラベルは日下部の字だが本人は書いた覚えがない。
- 早瀬のテープ再生→全部戻る→停止で曖昧に薄れる（「あの、派手な上着の人は」→「あの人」）。@record r01。
- 苑：火鉢。八十四歳、まばたきをしない。依頼＝蔵のテープを宿のデッキでテープからテープへ（等倍）。「道は春まで開きません。ゆっくりやってくださいまし」。「重いほうのお荷物も、ご無事で」（重い荷物の話をしていないのに）。早瀬のことは「お気の毒に」だけ。「宿帳には、ご自分の手でお書きになりましたね」「ようございました」。苑→日下部「環」、苑→先輩「お客様」。
- 廊下：撮影は昭和六十三年の冬から、忘れないため。日下部は十五から撮っている。平成六年の字は「同じ字の人はときどき。親子とか」→先輩「親の字など知らない」。
- c1：p3「撮っても、撮った人間が忘れたら、誰が見るんですか」／p2 二度目も薄れる、日下部「何百回か試しました」／p1 手帳は残る、スマホのメモは白。
- 昼：鷺沼が窓際の席にも椀を置き、戻す。「……癖だ」。小春：鷺沼は昔から人数より一つ多くよそう（伊織の名残。回収はしない、ほのめかしのみ）。
- 囲炉裏：トキ「柱の傷、下から三つ目だけ斜め、知ってる気がする」。「どこにも行きませんよ」。段差を見ずに上る。
- 夜中：帳場で日下部が天気予報のテープを見ている（「日本海側の山沿いを中心に」「あすにかけて」）。中身は第十章まで伏せる。
- 分岐で変わる事実：なし。

### ch03 蔵（12/22）
- 蔵：裏の斜面の土蔵、裸電球、炭（電気の除湿機は三日で止まる）。何千本、昭和六十三年の冬から。「数えたことはありません」（日下部の口癖として二度目）。
- カビの見分け（白い粉＝軽い／蜘蛛の巣＝奥まで、甘いにおいは手遅れ）、切り貼り（切ると映っていた人が少し薄くなる）、ツメ（R4）。先輩の到着テープは「おとといの晩に」折ってある。
- ダビング：デッキ三台（再生・録画・控え）、ヘッド掃除、トラッキング。日下部が理屈で感心を隠す。先輩は外で「巻き戻し屋」と呼ばれている、と話す。日下部「いいですね、外は」。
- c1：p1 二人で並んでツメを折る／p2「考えておきます。先輩が次に撮られるようなことがあれば」／p3「守っている、というか折ってあるだけです」「先輩は、知らないので」。
- 小春が握り飯を持ってくる。紙に丸い字「うめ　こんぶ　しゃけ　こはる」。日下部は梅を最初に齧る。小春→先輩「{name}様」。
- 二階堂の棚：三十一本（平成六年〜今年、来なかった冬が二回）。R6。大女将は見せるなと言う。令和元年（七年前）の一本からトキが段差を見ない。@record r02。
- c2：p3 日下部が撮ったのは八本（十五から）、最初の一本は手が震えた／p1 見せるべきか相談、答えが出ない／p2「恋をし直す」に日下部が赤くなる。
- 新年会　昭和六十三年：子どもの冬景色、一番後ろで若い苑の手拍子、上座の空いた座布団（伊織、説明しない）。先輩が一小節口ずさむ。「知らないのに、知っている」。@record r03。日下部「冬景色という古い唱歌。この谷では冬になると誰かが歌う」。
- 夕方：苑が蔵の戸口に。奥の黒塗りの小さな棚＝苑の私物、触るな。日下部も触ったことがない。
- 夜：谷を出たら忘れるのか→「先輩のテープは、ここにあります。谷の外には、ありません」。

### ch04 砂嵐（12/23）
- 吹雪。スマホの写真は谷に入る前のものまで全部白（先輩は工房の棚の中身をぼんやりとしか思い出せない）。
- 黒電話：取次ぎの店の女将が「どちらの宿でしたか」を繰り返す。書いた端から分からなくなる。年賀状が一枚も来ない。
- 帳場で写し。日下部は帳場の奥で寝起き（「夜中に筆の音で起きられます」）。
- 広間：文吉がトキが部屋を出るたびに「トキ」と呼ぶ。トキは紺の毛糸の襟巻きを編んでいる（第八章で使ってよい）。
- 夜：宿じゅうのブラウン管が点く（@fx s1）。コンセントを抜いても消えない。画面に三階の廊下と人影。小春の悲鳴。実際の廊下に早瀬の映りの姿（@vis gh on）、足音が遅れる。
- c1：p2 先輩が前に立つ、人影が肩の横を冷たく抜ける、日下部「次は僕が前に出ます」／p3 日下部が素肌の手首を掴む、「離します」と言って離れない／p1 人影は白い画面をかざして歩き、「撮れない」「なんで、白いの」と口が動く、名前が「は」まで出かかる。日下部「強く覚えている人には、向くことがある」。
- 蔵：鍵のかかった蔵で控えのデッキが勝手に回っている（早瀬のテープ）。R5 を日下部が説明。停止で忘れる。テープは作業台の引き出しに鍵をかけて仕舞った（早瀬のテープの所在）。帰り道に、母屋の裏口から蔵へ、きちんと一列の小さな足跡（苑の手掛かり、説明しない）。
- 小春は廊下に座り込む。「知ってる人だった気がするのに」。鷺沼「寝ろ」。
- 帳場：日下部、子どもの頃に蔵でテープを回して廊下を誰かが歩くのを見た、怖くて止めた、向かなかった（第十章の母のテープの前置き）。先輩が半纏を掛ける。
- 先輩の到着テープ：足跡二人分＋坂の下、標識の向こうに人影（一回目）。一時停止で、背が高い男、片手に何か提げている。
- 分岐で変わる事実：なし。

### ch05 明日の分（12/24〜12/25）
- 12/24：小春の黒板「今夜のおしながき」、丸い字、「ケーキ（あります）」。日下部「宿に、クリスマスはありません」。鷺沼が材料を内緒でくれた。
- 蔵：小春「たまちゃん、お客様に懐くの、初めて見ました」。前の客のときは鍵を投げてよこした。小春は四年前に面接で住み込み。「みんなすぐ忘れちゃう、それがちょっと楽だった。今はちょっと違う」。
- 夕食：小さな丸いケーキ。文吉が苺をトキに移す。トキ「懐かしい味。初めて食べるのに」。
- 夜中：帳場で筆が立って丸い字を書く（十二月二十五日、せ、り）。
- c1：p1 日下部を起こして走る／p3 声が出ず布団の端を握る、日下部が指をほどいて手を握る／p2 筆を掴んで上書きを試みる、墨が弾かれて玉になる、「重ね書きは、できないんです」。
- 小春の部屋：「明日の分、ってやつだ」。寝ないで夜通し喋る。面接の日は大女将に撮られた、帳場の奥に十九の日下部。「私が取られたら、テープ、見てね」「止めなきゃいいじゃん」。「たまちゃんのこと、よろしく」「ないけど、されといてください」。
- 明け方：小春が朝風呂へ（先輩が付き添い、日下部は外）。湯気の中で「たまちゃんのことなんですけど……昔、すっごく大事なもの、自分で失くしたみたいで……夜中にずっと、それの」で取られる（fg 1→2→3→1→0）。湯の面に毛糸の切れ端。
- 先輩も日下部も小春を忘れる。日下部は寝間着・素足で脱衣所の外に立っていた理由が分からない。宿帳に丸い字。日下部の懐に「うめ　こんぶ　しゃけ　こはる」の紙（ch03 のもの）。眼鏡が曇っても拭かない。
- c2：p2 先輩が眼鏡を外して袖で拭く、「見えます」「先輩が」／p1 腕を引いて立たせる／p3「泣き方を、忘れたんです」（日下部は泣かない。初めて泣くのは第九章）。
- 宿帳の令和四年十一月→蔵の手前から三番目の棚。小春のテープ（大女将が撮影、帳場の奥に十九の日下部の背中）。日下部は最後まで止めない。@record r05。
- 帳場に小春の置いたケーキ二切れと「たまちゃんと{name}様へ　めりーくりすます　こはる」。誰のか分からないまま二人で食べる。
- 小春のテープの所在：蔵の手前から三番目の棚（作業台で再生後、そのまま）。
- 分岐で変わる事実：なし。

### ch06 平成六年（12/26）
- 苑の字のラベル（日下部の字は苑に八つから仕込まれた：いろはを百回、客の名前によく出る字を百回）。
- 平成六年の段で一本だけ前に飛び出したテープ「平成六年十二月　{name}様・お父様」。小窓はきれい（誰かが時々出して拭いていた。日下部、言わない）。
- 再生（dt 1994-12-19）：赤い長靴、毛糸の帽子の五つの女の子。背の高い男がハードケースを提げ、女の子の手を引く。女の子が肩の上で大きく手を振る。男「振らなくていいんだよ」と笑い、自分も手を上げかけてやめる。帳場で膝に乗せ、手を重ねて宿帳に書く「ここ。とめ。はね」「ほら、上手だ」。広間から冬景色、女の子も口を動かす。@record r04。
- 停止後：男の顔は抜ける。手の大きさだけ少し長く残る。先輩は五つより前を何一つ覚えていない（拾われた話は第七章で日下部に言う）。
- c1：p3 日下部に預ける（作業着の内ポケット）／p1 もう一度見る（笑い皺、鼻の横の黒子、首をかしげる笑い方→抜ける）／p2 モニターを消して自分で写し、自分でツメを折る。
  → 平成六年のテープの置き場所が分岐で変わる。以降は置き場所に触れず「平成六年のテープ」とだけ書く。
- 事故の接近①：奥の棚の雪崩。日下部が下敷き、眼鏡が真っ白。「この、トラッキングの……いや、トラッキングにしては、可動域が」「柔らかすぎますね、これは」「何のつまみ――」→先輩が眼鏡を外す→取り乱す「技術的な誤認です」。部位名なし。

### ch07 逆さ回し（12/27）
- 朝：トキの紺の襟巻きがもうすぐ編み上がる（文吉に。首が寒がり）。「どこで編みはじめたのか、もう忘れちゃった」。
- 宿のデッキが一台死ぬ（ピンチローラーが割れ、テープを噛む。替えなし）。残り二台＝写し一台・控え一台。
- 先輩が初めて重いケースを開ける：業務用デッキ、後付けの黒いスイッチ、鉛筆で「逆」。先輩「拾われたとき、これを抱えていたらしい。五つのとき、どこかのバス停で。雪の日」。施設の先生が預かろうとしたら泣いて離さなかった（覚えていない）。覚えているのは六つから。名前は蓋の内側の隅に褪せたマジックで {name}（大人の字＝自分と同じ字）。
