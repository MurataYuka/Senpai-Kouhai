## 0. 作品の芯（一段落）

雨の坂の町で、町一番の人形修繕屋・柘植匡が、古い給仕人形の「先輩」を毎朝巻いている。
十五年前、先輩は匡の「修繕の先輩」だった。孤児の見習いだった八歳の匡に、自分の体を開かせて修繕を一から教えた、この町で本当に一番の職人だった。人形に心を持たせすぎることを禁じる法で回収されるとき、先輩は泣いている十歳の匡に怖がる顔を見せないよう、自分の指で「恐れの歯」を「笑いの歯」の音に曲げ、笑ったまま解体された。
匡は十五年かけて、町じゅうに散った先輩の部品を一つ残らず集め直した。買い、盗み、一人は死なせた。半年前に組み上げ、目を覚ました先輩には、昔の記憶を入れていない。記憶筒は匡の上着の中にある。
直せる人間がすぐそばにいて、直さない。それがこの話のホラーの全部で、それでも愛は愛。

**ホラーの発生源は匡ただ一人。** 怪異は出さない。敵（回収局と蒐集家）は出るが、プレイヤーが一番怖いのは、いつも匡であるように書く。

## 1. 世界

### 螺子坂（ねじざか）
- 雨が年に三百日降る、急な坂の町。石畳、ガス灯、蒸気の昇降機（坂の途中に何基もある）、運河の市場。西洋風の町並み、人名は日本名。
- 坂に人形の修繕屋が軒を並べる。給仕人形（からくり人形）が傘を差して坂を行き来するのが町の景色。湿気は人形の大敵で、この町の人形はよく錆びる。だから修繕屋が多い。
- 坂の上：閉鎖された鳩羽工房の廃墟と、回収局の建物（溶解炉がある）。坂の中ほど：柘植修繕所。隣：笠井の傘屋。坂の下：運河と古物市。坂の脇の屋敷町：宇津木邸。

### 人形の仕組み（この世界の常識。作中で自然に出す）
- **ぜんまい**：背中の真ん中の鍵穴で巻く。一度巻けばおよそ一日動く。止まると眠ったようになる。人形は自分の背中に手が届かないので、**自分では巻けない**（例外の伏線は第十三章）。
- **情の櫛（じょうのくし）**：胸の奥にある、オルゴールの櫛のような部品。感情は櫛の歯が鳴ることで起きる。普通の人形は六本から十二本。
- **記憶筒（きおくづつ）**：真鍮の円筒に、覚えたことが小さな針として打たれていく。オルゴールの円筒と同じ仕組みで、外して回すと音が鳴る（記憶は音になる）。**針をやすりで削ると、その分の記憶はなかったことになる。**取り付け自体は簡単な作業。
- **鳩羽型**：この町の人形の櫛は、たいてい鳩羽工房の櫛の「写し」。鳩羽が四十年前に作った最初の櫛を型にして、町じゅうの職人が写してきた（真相：その最初の櫛は先輩の櫛。写しの櫛は、元の櫛の音に返事をする）。
- **関節**：古い高級品は白磁の球体関節。鳩羽の関節は釉の色で見分けがつく。

### 法
- **情動令**（十五年前に施行）：情の櫛の歯が十二本を超える人形は登記できない。見つかれば回収局が回収し、溶かす。
- **人形登記**：人形には持ち主の登記が必要。登記のない人形は回収される。
- **回収局**：坂の上にある役所。査察官が定期的に人形の櫛を音叉で検める（櫛の歯の数は、音叉を胸板に当てると響きで分かる）。

## 2. 人物

### 先輩（主人公）
- 名前は入力（`{name}`）。地の文では `{name}`。
- 鳩羽工房の最初の人形「壱号」。四十年以上前に作られた、背の高い給仕人形。白磁の肌と球体関節。見た目は二十代後半の美人。**情の櫛は二十四本**（違法）。
- 半年前、柘植修繕所の作業台の上で目を覚ました。それより前のことを何も覚えていない（いま入っている記憶筒は、匡が新しく作った空の筒）。
- **恐れの歯が曲がっている。** 怖がるはずのときに、笑いの歯と同じ音が鳴る。だから怖い場面でおかしそうに笑う。本人は「そういう癖のある古い型」だと聞かされている。他の感情はちゃんとある。
- **手が覚えている。** 頭は忘れているが、指が修繕の手順を覚えている。考える前に手が直してしまう（第二章から少しずつ）。
- エプロンの蝶結びを自分で結ぶと、**必ず左の輪が三ミリ大きくなる**（昔からの癖。手が覚えている）。
- 性格：飄々としていて、からかうのが得意。匡の濁流の横で平然とメイド服の裾を整えている。からかうと匡が照れるのを分かっていてやる。
- 登記：表向きは「給仕人形・旧型・櫛十二本・持ち主 柘植匡」。偽造。匡は登記証を先輩のエプロンのポケットに入れさせている（「僕が持つものじゃないので」）。
- 名前の由来（一行）：鳩羽工房にいた頃の名前。匡が覚えていて、登記に書いた。
- **メイド服の理由**（真相、第十二章の記録で明かす）：①給仕人形として作られた。②鳩羽の手が震えるようになってから、鳩羽の仕事を本当にしていたのは先輩だった。「仕える者の服を着ていれば、誰も人形の手元を見ない」。油まみれでも給仕服のまま、鳩羽の名前で町一番の修繕をしていた。③今着ている服は、匡が記憶だけを頼りに仕立てさせた写し。袖口のレースは匡が自分で編み直した。元の服の焼け残りの布切れが、エプロンのポケットの裏地に縫い込んである。

### 後輩：柘植 匡（つげ ただす）
- 二十五歳。柘植修繕所の主。腕は町一番（と町じゅうが言う）。
- 眼鏡：**真鍮の細いパント型、細い鎖のグラスコード付き。** 鎖の途中に小さな机の鍵が一つ下がっている（帳面の引き出しの鍵）。
- 他人の人形を触るときは薄い木綿の手袋をする。**素手で触るのは先輩だけ。**
- 生意気：理屈っぽい強がり、素直になれなさ。「反論があるなら理屈でどうぞ」。毒舌ではない。
- **嘘をつくとき、眼鏡の鎖を指に巻く。** 説明はしない。何度か見せて、プレイヤーに気づかせる。匡は先輩にほとんど嘘をつかない。つくのは「昔のこと」と「恐れの歯」についてだけ。
- **感情の振れ幅が、天井と底を往復する。**（結夏の要望の芯。「心電図みたいな感情」）
  - 天井：言葉が溢れて止まらない、同じ語を重ねる、大声、強く抱きしめる、泣きながら笑う、恍惚。
  - 底：短い文、丁寧すぎる敬語、にこにこしている、手元で刃物や工具を整えている、技術の話を淡々とする。底のほうがぞっとする。
  - 天井から底へ、底から天井へ、一場面の中で落差をつける。振り切れたあと本人が自分の振れ幅に振り回されて取り乱すのもよい。
  - 【書き方】静かな場面も「冷めた」のではなく「溢れすぎて音が消えた」状態として書く。淡々とした愛にしない。
- **照れの非対称**（結夏の要望）：自分から近づくときは一切照れない（技師の手つきで、当然のように距離ゼロ）。**先輩のほうから近づかれると、耳まで赤くなって取り乱す。**からかわれたらちゃんと照れる。
  - 真相：自分から触るのは「見習いの手」で、子どもの頃から慣れている。先輩のほうから来られるのは、一人の男として扱われることで、それが一番欲しくて一番怖い。
- **唇への口づけは、匡からは絶対にしない。**（第十三章で本人が理由を言う：「それは先輩から来るものなので」）。手、指先、額、髪、首筋の継ぎ目にはする。
- 地雷を踏まないための線：匡は腹黒ではない。計算で先輩を操らない。先輩に対しては隠し事はあっても、騙して得をしようとはしない。持ち主の立場を先輩に向けて使わない（使おうとすると自分で吐き気がする）。
- 芯（重いもの）：**直せるのに、直さない。** 恐れの歯も記憶筒も、匡なら一晩で戻せる。戻せば先輩は匡を怖がるかもしれない。思い出せば、匡はまた「後ろをついて回るだけの子ども」に戻る。だから戻さない。十五年分の部品集め（盗み、そして宇津木の大奥様の死）も含めて、全部自分で選んでやってきたことで、子ども時代のせいにしない。

### 町の人
- **笠井雛子（かさい ひなこ）**：隣の傘屋の女主人、四十代半ば。匡を子どもの頃から知る世話焼き。悪気なく昔の話をする。第十一章で屋根裏に匿ってくれる。
- **豆（まめ）**：修繕所の、手のひらほどのねじ巻きの小鳥。先輩が近づくと鳴く（その節は「夢の三番」の最初の一節）。真相：十五年前、先輩が八歳の匡のために作った。匡が十五年ずっと直して動かしてきた。喋らないのに機嫌がある。
- 修繕所の客：千草さん（老婦人、三毛猫の人形）、銭湯の湯番の人形、坂の昇降機の係の爺さんなど。Claude Code が足してよい。

### 敵
- **檜垣 弦（ひがき げん）**：回収局の査察官、五十代。同情の余地ゼロ。溶かす人形の櫛が最後に鳴らす音を、炉の脇の「聞き部屋」で聞くのが趣味。特に「怖がる音」が好き。十五年前、鳩羽工房から壱号を回収した本人。没収した櫛を裏で売りさばいてもいる。
- **宇津木 稜（うつぎ りょう）**：蒐集家の家の跡取り、三十歳。物腰が柔らかく、人形を「美しい」と言い、膝をついて手に口づけたりする。だが人形を物としか見ていない。一年前に母が死んだことを気にしていない。気にしているのは、その夜消えた「鳩羽の手（一対）」だけ。
- **鳩羽 宗玄（はとば そうげん）**：故人。人形師。壱号を作った。晩年は手が震え、壱号に仕事をさせて名声を保った。情動令のとき、自分の身を守るために壱号を差し出した。記録と人の話の中にだけ出る。

## 3. 真相の年表

- 四十年余り前：鳩羽宗玄が壱号（先輩）を作る。櫛二十四本。その櫛が「鳩羽型」の元になり、町じゅうで写される。
- 二十年前ごろ：鳩羽の手が震えはじめ、壱号が仕事を代わる。給仕服のまま、鳩羽の名前で修繕をする。
- 十七年前：孤児の匡（八歳）が鳩羽工房で歯車を盗もうとして先輩に捕まる。先輩は突き出さず、見習いにした。「この工房では私が先にいる。先にいる者は先輩と呼べ」。練習用の人形がないので、**自分の体を開かせて修繕を教えた。**匡が最初に油を差したのは先輩の右肩の第二球（「そこは鳴きやすい」）。先輩は匡のために、ねじ鳥の豆と、「夢の三番」を鳴らすオルゴールを作った。毎朝、見習いのエプロンの紐を先輩が結んだ（左の輪が大きかった）。
- 十五年前：情動令。鳩羽が壱号を差し出す。回収局の檜垣が回収に来る。先輩は、物陰から見ている十歳の匡に怖がる顔を見せないために、自分の左手の指で恐れの歯を笑いの歯の音に曲げた。最後に匡に言った言葉：「泣くな。直し方は、全部教えた」。笑ったまま運ばれた。
  - 先輩は溶かされる前にばらされ、部品は闇の競りで別々に売られた（鳩羽の白磁は高く売れる）。記憶筒は炉に入れられる寸前に、十歳の匡が盗んだ。櫛は檜垣が裏で売った。
  - 鳩羽はその年のうちに死に、工房は閉じた。
- 十五年間：匡は町の修繕屋に住み込み、腕を上げ、独り立ちし、町じゅうの人形を診るようになった。**診た人形の櫛に、一本だけ小さな針を足した。**「夢の三番」の最初の一節を聞くと、その人形が見たもの（鳩羽の白磁の部品がどこにあるか）を匡に知らせる針。町じゅうの人形が匡の目になった。部品は二十三。古物市で買い、質屋から盗み、修繕を口実に持ち主の人形と入れ替え、櫛は檜垣の裏の売り先から買い戻した。
- 一年前：最後の部品、左手（と右手、一対）を持っていたのが宇津木の大奥様。売らないと言われた。匡は大奥様の給仕人形「お鈴」を診たとき、「夜のうちにあの手を持ってくる」ように仕込んだ。夜、お鈴が硝子の箱から手を出したところで大奥様が起き、手にしがみついた。お鈴は「離すな」の命令どおり離さず、大奥様は階段から落ちて死んだ。お鈴は手を匡に届けた。匡は止めなかった。
- 半年前：先輩を組み上げる。記憶筒は新しい空の筒にした。恐れの歯は直さなかった。目を覚ました先輩に「おはようございます、先輩」と言った。

## 5. 演出

### 枠（`game/theme.css` / `game/effects.js`）
- 左右の縁：白いレース（先輩のエプロンの縁のレース）。真鍮の細い線が縁取る。
- 上辺：横倒しの**真鍮の円筒（記憶筒）**がゆっくり回っている。針が章ごとに増えていく（新しい筒に、匡との日々が打たれていく）。第一章ではほとんど針がない。
- 下辺：**オルゴールの櫛**。二十四本の歯。**そのうち一本だけ、最初から少し曲がっている**（目立たせない。気づく人だけ気づく）。
- 文字の後ろ（`#back`）：窓の雨。斜めに流れる細い雨脚と、硝子を伝う水。文字は濡らさない。
- **匡の目線の場面**：枠のレースが灰色にくすみ、上辺の円筒が**別の筒**に替わる（針がびっしり打たれた古い筒）。説明しない。`@vis pov k` で切り替え、`@vis pov off` で戻す。
- 天井の場面：枠（`#frame`）を小さく揺らしてよい（`@fx shake`）。**本文の箱と文字は揺らさない。**
- 底の場面：雨の音（雨脚の描画）を一瞬止める演出が効く。

### 第十五章の大演出（テキストボックスの後ろ）
- 救出の山場で、背景が**先輩の背中の板が開くように左右に開き**、画面いっぱいに真鍮の機構が現れる：ゆっくり回る記憶筒、櫛、ぜんまい、歯車。櫛の歯が一本ずつ光って鳴る（音は無くてよい。光で）。曲がった一本だけが、別の色で光る。

## 6. パラメータとエンディングの条件

### パラメータ（`config.vars`）
- `p1`：トゥルー寄り（対等。自分で選ぶ。匡を一人の人として見る）
- `p2`：先輩主体メリバ寄り（先輩が導く、取り戻す、匡を自分のものとして扱う、昔の先輩の側へ）
- `p3`：後輩主体メリバ寄り（先輩が匡の手に委ねる、任せる、匡のやり方を受け入れる）
- 範囲 0〜30。第一章から第十四章まで、各章二回、三択で、選んだ方向に +1。

### エンディングの決まり方
- **第十五章の終盤の一か所の選択（四択）で、ED4・ED5・ED6 が直接決まる。** 回収しやすいように、パラメータに依存させない。
- その四択で「匡の手を取る」を選んだときだけ、パラメータで ED1〜3 に分かれる：
  - `p1 >= p2 && p1 >= p3` → ED1
  - `p2 > p1 && p2 >= p3` → ED2
  - それ以外（`p3 > p1 && p3 > p2`）→ ED3

## 11. 書き方の指示（すべて【書き方】。本文に書き写さない）

- 【書き方】地の文は三人称、カメラは主人公寄り。主人公の内面（考え・気持ち・回想）は書かない。先輩の恐れの歯の「笑い」は、▷の行と行動（笑った、肩が揺れた）で見せる。「おかしくもないのに」のような内面の説明は書かない。
- 【書き方】匡の目線は、指定した場所だけ（三・七・十・十三章の終わり、ED3 の最後）。`@vis pov k` で入り、出るときに `@vis pov off`。
- 【書き方】匡の天井と底：天井は言葉が溢れて重なる、大声、抱きしめる。底は短い、丁寧、にこにこ、工具。地の文で「声が低くなった」「平らな声で」のように声の調子を実況しない。台詞と行動で見せる。
- 【書き方】匡の口癖の「全部」は、天井の場面で重ねる。一章に一、二回まで。乱発しない。
- 【書き方】照れの非対称を毎章どこかで一度は見せる。ただし同じ型（耳まで赤い、だけ）を繰り返さない。照れ方を毎回変える（眼鏡を押し上げそこねる、工具を落とす、敬語の文法が崩れる、理屈が途中で迷子になる、豆に話しかけて逃げる、など）。
- 【書き方】嘘のときに鎖を指に巻く仕草は、説明しない。地の文で「嘘をつくときの癖」と書かない。
- 【書き方】眼鏡の鎖を先輩が引く・絡める仕草は、冒頭の一場面を除いて本編で二回まで。
- 【書き方】先輩は怖がらない。悲鳴は上げない（ED1・ED6 で恐れの歯が戻ったあとは別）。町の人、稜、檜垣の部下は普通に悲鳴を上げてよい。匡も天井の場面で一声二声は上げてよい。
- 【書き方】匡の加害（宇津木の大奥様の死）は、匡の口から、淡々と語らせる。弁解させない。だが匡を「腹黒」にしない。計算ではなく、溢れた結果として。
- 【書き方】身体の損壊（人形の分解、檜垣の回想、猟犬）は、部品の音、螺子の転がる音、置かれた物、雨で見せる。人形がばらされる描写は、人間の損壊のように生々しくしすぎない。
- 【書き方】ホラーは匡から来る。夜の物音、二階の旋律、にこにこした刃物研ぎ、屋敷の人形が一斉に頭を下げる、小瓶の棚。怪異は出さない。

## 12. かぶり防止

### チャットで結夏が読んだもの（本編でそのまま繰り返さない）
- 冒頭の一場面（最後の節）。第一章の頭として一度だけ使う。以後、「起動まで四十二秒」「物理的な問題です。反論があるなら理屈でどうぞ」「右肩。第二球」「全部、全部、全部僕が直します」「こっちから行くのと、そっちから来るのとでは、話が違う」「結び目の輪、左が三ミリ」「毎朝ずれてるからです」「先輩だからです」「錆びないように、僕の目の届くところに」を本編で同じ言い回しで繰り返さない（第十三章で「左が三ミリ」に触れるのは物語の回収なので可。言い回しは変える）。

### 過去作と被らせないもの（確認済み）
- 「記憶を消されて『初めまして』」（よいまがき）：ED3 は毎朝の削りで、相手を選んで初めてに戻すのは匡。言葉として「初めまして」は使わない。
- 「冒頭の一文・場面をノーマルで反復」（よいまがき・あさなぎ）：ED3 は匡の目線から冒頭を見直す形で、文章はそのまま繰り返さない。
- 「急所を預ける」系（喉・脈・心拍）は使わない。ぜんまいの音に耳を当てるのは記録 r05 の思い出の一行だけにする。
- 「数える・カウントダウン」（あさなぎ）：日数を数えない。ED3 の小瓶も数を書かない。
- 「心臓の音・心拍」の言及で照れる型（よいまがき・あさなぎ）：使わない。
- 「睫毛の本数」（まきもどし）：使わない。
- 「天気の話をするみたいに」「紙のようだった」「早かった。早すぎた。」型：使わない。
- 「手枷の鎖で抱き寄せる」（さかひとや）：眼鏡の鎖は先輩が指に絡める・引く程度。抱き寄せる道具にしない。
