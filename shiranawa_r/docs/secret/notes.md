各章を書き終えるたびに、下の形で追記する。

```

- 実測文字数：

- 人物の状態（怪我・失った感覚・居場所・持ち物）：

- 継ぎ目の点検：○箇所、修正○件
- 口調の実況の点検：○件修正
```

## 識別子の対応表

- `data/chNN.js`：第N章。章の頭のラベルは `chNN`。場面ラベルは `sNNxx`。
- `data/edN.js`：エンディング。頭のラベルは `edN`（ed1=ED1 … ed7=ED7、ed8・ed9=追加）。
