## 0. 一枚の絵と、大きな嘘

**一枚の絵：** 赤い花びらまみれの、ファンシーな結婚式場。白いドレスの花嫁と白いタキシードの花婿が、右手と左足で繋がれたまま、晴れやかな司会の声に急き立てられて「式次第」どおりに館を進む。

**大きな嘘：** 館に満ちている香り（司会が「ブーケの香り」と呼ぶ薬）を吸っていると、死んだ肉と血が花に見える。
- 血、肉は赤い花びらに見える。脂は黄色い花、骨と歯は白い花に見える。
- 腐った匂いは、濃すぎる生花の匂いに感じられる。
- 建物の汚れ、黴、染みは、花模様の飾りに見える。廃墟が、新品のきらきらした式場に見える。
- 生きている人の姿はそのまま見える。生きている体から流れる血は、流れ出たそばから花びらになる。
- 濃く吸うと、記憶が抜ける（名前も、自分の暮らしも）。二人が記憶を失っているのはこのため。

本当の館は、二十年以上前に潰れたバブル期の結婚式場の廃墟です。宴会場の円卓には、過去にここで「式」を挙げさせられた人たちの亡骸が、礼服のまま座っています。

**タイトルの意味：** 「はなむけ」は「餞」。旅立つ人に贈るもの。結婚式は門出で、この館では門出は死です。表の意味は「花向け」（花を向ける、花を見せる）。最後まで読むと両方が分かるようにする（作中でタイトルの漢字を説明しない。読み手が気づく形でよい）。

**三本の対比の軸：誰が、誰の目に、花を見せ続けるか（そして、誰が誰の名前を持っているか）。**
- トゥルー：誰も花を見せない。二人とも本物を見たまま、名前を呼び合って出ていく。
- 主人公主体メリバ：先輩が渉に花を見せ続ける。渉の名前は先輩だけが持っている。
- 後輩主体メリバ：渉が先輩に花を見せ続ける。先輩の名前は渉だけが持っている。

## 1. 館「ブライダルパレス花宴（かえん）」

- 山の中腹に建つ、バブル期の大型結婚式場。平成元年に開業し、平成十三年に廃業。三階建ての本館と、渡り廊下で繋がった別棟のチャペル「ステラ」。正面玄関は鎖で閉じられ、窓はすべて板で塞がれている（薬の中では、窓は分厚い薔薇の垣根に見える）。
- 館じゅうの空調の吹き出し口から、香りが流れている。香りの元は、一階の厨房の奥の機械室にある。**ただし、最上階の大宴会場「鳳凰の間」だけは、司会が最後の夜に香りを止める。**
- 館内放送：天井のスピーカーから、司会の声が流れる。古いテープの録音（若い頃の澄んだ声）と、生の声（年老いて嗄れた声）が混ざる。最初は録音だけ。第十章で、録音と生の声の違いが分かる。

### 館の決まり（可愛い手書きのカードで、あちこちに置いてある）

- 「死がふたりを分かつまで、おふたりは離れられません」（手錠と足枷の鍵は司会が持っている。片方が死んだら、司会が見ていて外させる）
- 「式次第の順番をお守りください」「館内は走らないでね」「お花には、なるべく触らないでね」など。可愛い文字と中身の不穏さの落差で見せる。

## 2. 人物

### 先輩（主人公・名前入力 `{name}`）

- 三十一歳（本人は知らない）。背が高く、余裕のある美人。平然としていて、大真面目に発想がずれている（冒頭のカニ歩き）。物怖じせず、血も花も平気な顔をする。
- **正体：特殊清掃員。** 孤独死や事故の現場を片付ける仕事を、一人で請け負っている。親族とは疎遠で、一人暮らし。誰も探しに来ない。
- 彼女の平然さには理由がある（死と腐敗に慣れている）。記憶がなくても体が覚えている：
  - 匂いに強い。花の匂いの「奥」を嗅ぎ分けようとする。
  - 手袋をしたがる。素手で花に触るなと言う（第六章）。
  - 「体液」「死後」のような言葉が、ふと口から出る（第六章。渉が「なんでそんな言葉が出てくるんですか」）。
- 第十三章で記憶が戻ると、亡骸の状態から年数を言い当てる（「この卓は二年くらい、向こうは五年」）。【書き方】冷たさではなく、職人の手つきとして書く。
- 先輩が取り乱すのは一度だけ（第十一章、ゴムの足枷を限界まで引いて渉を引き戻す場面）。
- 地の文での呼び名は「花嫁」→ 第十章で `{name}`。

### 後輩：芹川 渉（せりかわ わたる）

- 二十四歳。敬語、生意気（理屈っぽい強がりと素直になれなさ。毒舌ではない）。怖がりで、すぐ青くなるが、手だけは几帳面に動く。ツッコミ担当。
- **眼鏡：茶色のサーモント**（上の縁だけ太いセル、下は細い金属）。少し古風。**正体は、祖父・芹川修造の形見の枠にレンズだけ入れ替えたもの。**
- 胸ポケット（本来なら花を挿す場所）に、青い軸のノック式のボールペンが一本。いつもシャツの胸に挿していたもの。先輩に「ボールペン君」と名付けられる。
- **芯：** 祖父母に育てられた。祖母・芹川ふみ（八十三歳）は四年前から認知症。渉は大学を辞めて、夜勤の倉庫の仕事と介護を一人で回してきた。家じゅうに、このボールペンで書いた付箋が貼ってある（「ここはトイレ」「ごはんは冷蔵庫」「今日はデイサービスの日」）。
  - 祖母は二年前から、渉を亡くなった夫だと思っている。「修造さん」と呼ばれる。渉は祖母が落ち着くので、祖父の眼鏡をかけ、祖父の役をするようになった。**この二年間、「渉」と呼んだ人は一人もいない。** 自分の名前が、家の中で死んでいた。
  - 館では、記憶がなかった。名前も、祖母も、付箋も、修造さんもなかった。**怖くて死にそうなのに、楽だった。** それに気づいてしまったこと、そう思った自分を、渉は一番許せない。
- **介護の癖（記憶がなくても体が覚えている）：**
  - **口で息をする癖。** 排泄物の匂いを吸わないように身についたもの。そのせいで香りを吸う量が少なく、先輩より早く本物が見え始め（第八章）、先輩より早く記憶が戻る（第九章）。第二章で先輩が気づく伏線。
  - **何にでもラベルを書く癖。** 壁に矢印、扉に「×」「出口ではない」。第一章から。
  - **人を抱える手際。** 第五章で先輩を抱き留めたとき、「移乗」「介助」という言葉が口から出る。
  - 古い歌を知っている（祖母のラジオ）。第三章で館内に流れる「愛の挨拶」を、なぜか口ずさめる。甘い卵焼きが好き（第八章）。
- 地の文での呼び名は「花婿」→ 渉の目線の場面では第九章から「渉」→ 先輩の側の地の文では第十二章から「渉」。

### 司会・白鳥 恭一（しらとり きょういち）

- 七十歳。花宴の専属司会者だった。バブルの頃、「白鳥マジック」と呼ばれた売れっ子。白いタキシード、マイク。
- 廃業した館を買い取り、二十年近く、見ず知らずの二人を連れてきては「式」を挙げさせてきた。選ぶのは「誰にも探されない人」。
- 思想（同情の余地ゼロの狂気）：「誓いは守られて初めて誓いです。人は必ず誓いを破る。だから私は、破られる前に、式を閉じて差し上げる。死がふたりを分かつまで——その日のうちに、きちんと分かってさしあげる」。
- **悪意：** 花を見せるのは慈悲ではない。最後の夜に香りを止めて、二人が「本当のお相手」と本物の会場を見た瞬間の顔を見るのが、何よりの楽しみ。「本当のお姿を見て、それでも誓えますか？」。誓えずに相手を差し出す顔が好き。
- 【書き方】いつも晴れやかで、司会の決まり文句と駄洒落を絶やさない。怒っても司会の口調のまま。人間味のある過去や涙は与えない。
- 結末：第十五章で、千鶴が落としたゴンドラの下敷きになる。

### 介添人の着ぐるみ「ブーケちゃん」／早瀬 千鶴（はやせ ちづる）

- 花宴のバブル期のマスコットの着ぐるみ。頭が大きな笑顔の花束で、白い手袋、フリルの介添人の服。薬の中では可愛い。本物はすり切れて汚れ、頭の花は干からびている。
- 中身は、三年前の「花嫁」だった早瀬千鶴（三十四歳）。相方の花婿（二人は互いを「時計さん」「マニキュアさん」と呼び合っていた）が死んで、自分だけ生き残った。毎朝司会に濃く香りを吸わされ、記憶をほとんど失ったまま、司会の命令で動く「介添人」にされている。
- 命令で二人を追いかけ、捕まえ、お色直しをさせる。けれど、席札の裏に鉛筆で書き置きを残して、館のあちこちに隠している（**記録 r01〜r10**）。
- 第十四章で、先輩の手に鍵を滑り込ませる。第十五章で、ゴンドラを司会の上に落とす。

### もう一組：ネクタイさん と ネイルちゃん

- 控室「二」で目を覚ました、もう一組の新郎新婦。記憶がない。互いを持ち物で呼び合っている（ボールペン君と同じ）。本名は最後まで出さない。
- **ネクタイさん：** 四十代半ばの、汗っかきで実直な男。小学生の娘がいそうな父親の顔で、ネイルちゃんを守ろうとする。第六章、ケーキ入刀で死ぬ。
- **ネイルちゃん：** 二十代前半、派手なジェルネイル、気が強くて口が悪いが、根は怖がり。先輩と渉に「あんたら付き合ってんの？」。第六章でネクタイさんが死に、足枷と手錠が外れ、ブーケちゃんに「お色直し」へ連れていかれる。第七章で、介添人の服を着せられ、濃く香りを吸わされて、笑顔で「どちらさまですか？　おめでとうございます」と言うようになっている。第十章で給仕をしている。トゥルーでは助け出される。

### 祖母・芹川 ふみ（館には出てこない）

- 八十三歳。渉を「修造さん」と呼ぶ。渉がいなくなった二日目に、デイサービスの送迎の人が気づいて、ケアマネージャーがショートステイに預けている（トゥルーなどで明かす）。

## 4. パラメータとエンディングの条件

| パラメータ | 意味（記号のまま使う） |
|---|---|
| `p1` | 本物を見る、向き合う（トゥルー） |
| `p2` | 先輩が渉を囲う、持っていく（主人公主体メリバ） |
| `p3` | 先輩が、渉に見せられる景色を受け入れる（後輩主体メリバ） |

- 第一章〜第十三章の各章に、三択の「気持ちの選択肢」が一つずつ（それぞれ +1）。第十五章の最後に一つ（それぞれ +2）。取りうる値は各 0〜15。
- 各章には別に「生き延びる選択肢」が一つずつある（第一章〜第十四章）。一つがゲームオーバーで、二つは安全（パラメータは動かない）。

### 本編エンディングの決まり方

- **第十四章の最後の四択で、まず道が分かれる**（パラメータに依存しない）。
  - 「誓わない。鎖のまま二人で出る」→ 第十五章へ
  - 「鍵を開け、渉を出口へ押し出す」→ **ED5**
  - 「香りの瓶を開け、二人で深く吸う」→ **ED6**
  - 「司会の言うとおり、ナイフを取る」→ **ED4**
- **第十五章の最後で、パラメータで分かれる。**
  - `p1 >= p2 && p1 >= p3` → **ED1**（同点はトゥルー）
  - `p2 > p1 && p2 >= p3` → **ED2**
  - それ以外 → **ED3**
- 追加エンディング `ed07`・`ed08` は、本編六種を全部回収すると一覧に現れる（`'all-main'`）。

## 5. 章ごとの設計

各章の「生き延びる選択肢」と「気持ちの選択肢」の並び順は、ここに書いた順のまま使う。ゲームオーバーの中身は第6節。

### 第一章「ご入場」（一日目・朝）

- 冒頭の一場面（第13節。全文をそのまま章の頭に使う）。拍手は録音（テープの回転音が混じる）。ワーグナーの婚礼の合唱（いわゆる「結婚行進曲」）が、割れた音で流れる。
- 花道の廊下を進む。二人は前を向いて、ぎりぎり歩く。ゴムの足枷のせいで歩幅が合わず、何度か引き戻される。【書き方】手錠は「硬い限界」（がつんと止まる）、ゴムは「じわじわの綱引きと反動」。違う種類の窮屈さとして書き分ける。
- 鳳凰の間の両開きの扉は鎖で閉じられ、「本日の披露宴は、四日目の夜でございます」の札。
- 一階へ降りる大階段とロビー。正面玄関は鎖。窓は分厚い薔薇の垣根で塞がっている（本物は板）。
- **花婿が、胸のボールペンで壁に矢印を書く。** 扉には「×」。花嫁が何をしているのか訊くと「迷子になると困るので。……なんで僕、こんなに書くのに慣れてるんでしょうね」。
- ロビーの館内図と、式次第のカード。館内放送で司会が名乗る（録音）。「本日の司会を務めます、白鳥でございます。おふたりには、式次第に沿ってお進みいただきます」。
- **生き延びる選択肢**（大階段の下、頭上でシャンデリアが軋む）
  1. カニ歩きで壁際へ寄る（安全。花婿が「今だけは正しいです」）
  2. 走って階段を駆け上がる → `@gameover g01`
  3. その場で二人で身を低くする（安全）
  - 安全な道ではシャンデリアが落ちて、床一面に花が散る（中身は空のシャンデリアと、溜まっていた「花」。誰も死なない）。
- **気持ちの選択肢**（花びらだらけのロビーで一息ついて）
  1. 花婿の肩の花びらを払ってやり、離れるなと言う → `p2`
  2. 綺麗だから、深く考えないことにする → `p3`
  3. 花びらをすくって、匂いの奥を確かめる → `p1`

### 第二章「ゴンドラでのご登場」（一日目・昼）

- 吹き抜けのエントランスホール。天井から白いゴンドラが吊られ、ゴンドラにも花。司会（録音）が「昭和の華、ゴンドラでのご登場！」。ホールの向こう側へ渡るには、ゴンドラか、壁際の点検用の梯子か。
- **伏線：口呼吸。** 花嫁が、花婿がずっと口で息をしているのに気づく。「癖です。……何の癖かは分かりませんけど」。花嫁が真似すると「真似しないでください」。
- 記憶がない者同士の会話。互いの手、服、癖から、相手がどんな人か当て合う。花嫁の手は荒れている（薬品の荒れ）。
- **生き延びる選択肢**

## 13. かぶり防止

### 結夏がチャットで読んだもの（本編でそのまま繰り返さない）

- **冒頭の一場面（第14節）。** 第一章の頭として一度だけ使う。以降、カニ歩き、「ボールペンは持ち物です」「せめて人間の部分から」「済んでる可能性を出さないでください」「要約しないでください」の型を本編で繰り返さない（ED6 のカニ歩きは、ダンスとして意味を変えて一度だけ）。
- 結夏が相談中に挙げた温度の例「明かり、点けない方が良かったな」は、本編でそのまま使わない。

### 過去作の型（使わない）

- 「記憶を消されて『初めまして』から再会」、記憶が場所に置いてある、名前を呼ぶ／返事をするルール、子どもの偽証、食べる／食べさせる、手枷の鎖で抱き寄せる型の決め場面、知識（規定の長さ）で自爆する型のそのまま、遺影ではない「骨の枠」、蓄音機と社交ダンス、ゴンドラの唄、試し行動。
- 先輩が取り乱すのは第十一章の一度だけ。

## 15. 零壱の非公開メモ（制作には使わない）

- ネタ帳から拾ったもの：関係性15（一定距離以上離れられない）を手錠とゴムの二重に、展開01（閉じ込められる）、展開12（記録・手紙から死者の本音）。展開15（一晩だけ眠れない）を第八章に。
- 零壱の隠し玉：介護で自分の名前を失っていた後輩（家では祖父の「修造さん」）と、記憶のない館で「楽だった」と気づいてしまう罪悪感。先輩の正体の特殊清掃員。
- 先輩の名前は結夏が入力する。零壱は何も仕込まない。
- 追加エンディングの曲は、結夏がそのエンディングに進む直前に、曲名と出典を伝える。
